# 中文视频提示词词库 v1.1
## ——从文学写实派里筛出来的高质量动作动词与器物名词

> **v1.1 实测结论（2026-10-15，3 组对照验证）：**
> 真正拉开差距的是**带空间约束的展开写法**，不是单字本身——
> ① **轨迹**（从上往下砸）② **路径依附**（顺着墙瘫坐）③ **分段动态**（碗震起又落下）④ **运动约束**（贴着水面横向飘散）。
> 因此：**所有 A 档词一律带轨迹修饰语使用**（抡→抡起右臂从上往下）；纯单字直喂的独立增益未验证。
> 单字词的真实角色是"检索入口"：你词穷时想不起轨迹，但想得起这个字，再把它展开。
>
> **用法三句话：**
> 1. **A 档词**：带上轨迹修饰语写进提示词（抡起右臂、从上往下）。**不要只写单字**——实测证明增益来自修饰语。
> 2. **B 档词**：不要直喂（模型会退化成拿/扔/看/走），抄右边的"展开写法"。
> 3. 每个词留了「实测」列：生成翻车了就把它从 A 降到 B，词库越用越准。
>
> **适用**：中文直喂模型（可灵、即梦等）。走英文链路的模型（Sora 等）一律用展开写法。
> **主要矿脉**：汪曾祺、阿城、萧红、老舍、沈从文（下文标「源」仅示典型来源，不代表独占）。

# 第三部分·B：气质词 → 身体语言对照表

> C 档处理"情绪"（苍凉/孤独）；这里处理**角色气质**——用户想表达"这个角色很野/很稳/很狂"，直接写气质词模型抓不住，要翻译成**身体姿态 + 重心 + 线条方向**。
> 实战来源：机甲双塔项目（2026-10-20），用户反复说"太潇洒了要野性一点""要像暴走的野兽"。

## 最容易混淆的反义对：野性 vs 潇洒

| 气质 | 身体语言（直接抄进提示词） |
|---|---|
| **野性 / 兽性** | 重心下沉、脊背弓起、颈部前探、动作留滞、线条向下压、身体不对称、指爪微张 |
| **潇洒 / 帅气** | 舒展、对称、重心高、动作利落收尾、线条上扬、姿态挺拔 |

**记住**：野 = 压缩·沉·滞；帅 = 舒展·高·利落。两者相反——想要野就别写"舒展、利落、帅气"。

## 其他高频气质

| 气质 | 身体/画面语言 |
|---|---|
| 狂暴 / 失控 | 松垮佝偻、肩一高一低、头歪向一侧、双臂无力垂荡、重心不稳（如暴走八神待机） |
| 沉稳 / 神性 | 挺拔、对称、动作缓慢、悬浮感、俯视姿态 |
| 压迫感 | 低角度仰拍 + 主体占满画面 + 暗部重 + 轮廓硬光 |
| 脆弱 / 渺小 | 大远景 + 高角度俯拍 + 主体在画面边缘 + 大量留空 |
| 警觉 / 蓄势 | 双膝微屈、重心压低前倾、肩背微耸、下颚收紧（如立定跳远前） |
| 冷峻 / 疏离 | 面部肌肉松而不动、下颌微收、眼神平直无波、肩颈放松但不松垮、动作极简省 |
| 妩媚 / 风情 | 重心偏移成 S 曲线、肩略后展、下巴微扬侧垂、动作慢而连贯、指尖舒展 |
| 猥琐 / 阴鸷 | 含胸缩颈、眼神斜向上瞟、手小动作多（搓手/摸脸）、重心游移不定、笑不到眼 |
| 天真 / 鲜活 | 重心高而轻、动作幅度大且快、肢体舒展外放、头经常偏转、眼神直视发亮 |
| 疲惫 / 颓丧 | 肩塌背弓、脖子前伸、步子拖沓、手臂垂荡无力、眼睑半垂、动作延迟 |
| 高傲 / 睥睨 | 下巴抬高、视线俯视、脊背笔直、步伐从容慢、很少回头、重心稳居中 |
| 贱兮兮 / 得瑟 / 调皮（拟人、动物角色高频） | 眯眼、歪头、单侧嘴角上扬、斜瞟镜头、舌尖微吐、耳朵微后压、尾巴轻翘；别写"可爱/贱"本身 |

**用法**：用户说"要野/要狂/要有气场"，先查此表换成 3 个以上身体状态词，别只丢一个气质形容词。

**动物 / 拟人角色补注**（2026-11-04 实测）：这类角色的"表情"完全靠上述**五官与头部姿态**承载，
没有人类肢体可用，所以更要凑够 3 个以上可见细节；品种差异（毛色 / 眼色 / 体型 / 耳朵 / 尾巴）
要写死，否则跨段落会漂成另一只。群像同框时每只的**站位坐标**另配尾帧锚图锁，见 `shot-continuity.md` 三·补。

# 附：使用模板（拼装顺序）

> **v1.1 新增：动作写法公式（实测验证的核心模式）**
> `动词 + 轨迹（从上往下/横向/顺着X） + 受力结果（分两段写：震起又落下/弹起又滚开）`
> 写任何动作前先问三个问题：往哪个方向？沿着什么路径？造成了什么两段式后果？

> **v1.2 补一个维度：参照物（2026-10-20 实战验证）**
> 动作/姿态卡在"说不清具体长什么样"时，补一句 `像 [某个具体动作] 的瞬间`，比堆形容词有效。
> 例："双膝微屈，大腿小腿约 150 度，**像立定跳远前蓄力的一瞬**，不是深蹲"——这句话模型能精确执行；
> 只说"蹲一点"则完全跑偏。公式升级为：
> `部位 + 精确状态（角度/高度/方向）+ 参照物（像XX的瞬间）`

```
[场景包名词 2-3 个] + [主体] + [A档动词或展开写法，一次只一个动态] + [光线锚点 1 个] + [运镜 1 种] + [风格词]
```
