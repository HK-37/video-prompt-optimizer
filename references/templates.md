# 提示词模板库（templates）

> 用途：可复用的提示词骨架，填空即用。**存方法不存图**——图在使用者自己维护的素材库（素材索引放使用者的项目 memory，不内置于本 skill）。
> 用法：找到匹配场景的模板 → 按 `[方括号]` 填空 → 套第 4 步 8 维补全 → 过第 4.6 步审核自检 → 提交。

## 通用骨架（所有镜头套这个）

```
[场景包名词2-3个] + [主体及造型] + [单一主动态(动词+轨迹+分段受力)] + [景别+构图] + [光线来源+光比] + [运镜1种] + [色调+风格词]
```

末尾护栏层（2-4 条，防崩坏）：`画面锐利清晰、人体/机械结构稳定不变形、固定机位不抖动`

## 模板 1：人物施法起手（背面 / 正面）

**适用**：紫方/红方抬手凝能量球。**优先用背影**（绕真人脸审核，剪影氛围更好）。

```
夜晚城市高塔顶端，[正面/背影]，中近景，一名[长黑风衣/短发短夹克]的[修长男子]，[缓缓抬起左手/猛地抬右手向上抓握]，掌心[凝聚一颗紫色水晶质感光球/炸开赤红岩浆状火球、火星四溅]，[紫光/赤红光]是主光源，[自下而上把下颌照成冷紫/从下往上硬光打亮半张脸另半脸没入暗部]，背景城市灯海虚焦，高对比，镜头固定机位，薄雾空气透视，电影级夜景，写实3D渲染，8K高细节。
```

**参考素材**：由使用者自行准备有使用依据的对应造型图；本仓库不附带私有素材或固定路径。

## 模板 5：多镜头三段式（一条视频内切镜头）

**适用**：一条生成里要"先A再B再C"，导演模型（即梦）用时间戳分段。

```
一段[X]秒的多镜头电影短片，三个镜头清晰切换：
0-[X/3]秒：[镜头1场景+主体+动作+景别+光]，镜头[运镜]。
[X/3]-[2X/3]秒：切镜头为[景别]，[镜头2内容]。
[2X/3]-[X]秒：切镜头为[景别]，[镜头3内容]。
三个镜头清晰切换，像剪辑好的分镜。[色调]基调，逆光轮廓勾边，电影感，写实3D渲染，8K高细节。
```

**验证边界**：该结构来自有限案例观察，不是所有导演模型或题材的成功保证；本仓库不附带案例成片，效果以实际生成验收为准。

**注意**：单条视频内多镜头**连贯性最好但可控性最差**——任一处不满意整条重跑；内容多的话单点踩审核线整条报废，复杂片建议拆段。

## 模板 6：机甲造型定妆图（i2i）

**适用**：要先出一张角色定妆图，再用它锁后续所有镜头。

```
[保持参考图中机甲的造型语言不变]，[改变配色/姿态/机位为：……]。[身材比例数值化：腿占身高三分之二、四肢细长、肩宽是腰宽N倍]。装甲[哑光合金+分件结构线+暗纹微光]，头部[光洁无角头盔/机械棱面角冠]，姿态[弓背蓄势/松懈佝偻/挺拔站立]，[机位]，[光线来源+光比]，身后[巨大能量光环溢出画框]，[色调]，写实3D渲染，8K高细节。
```

**要点**：配色比例、标志部件（角的角度长度）、体型（肩宽腰宽比、腿长占比）都要写具体——定妆图是后续镜头的"视觉合同"，模糊了就会各画各的。

## 模板 7：氛围空镜 / 转场呼吸镜

**适用**：两段情节之间的过渡空镜，或单纯要氛围的镜头（建立情绪、给节奏留白）。

```
[场景包名词2-3个 + 1个质感细节]，[时间段]，画面里没有任何人物（纯环境）。[主体物件]静静立在画面[位置]，[动态：炊烟贴着水面横向飘散/浮尘在光柱里缓缓翻滚/雨丝斜打在玻璃上]。大远景/全景，低地平线构图，大面积负空间，[光线来源+方向]，[色调]，镜头[缓慢平移/固定]，画面锐利清晰，写实质感。
```

**要点**：空镜是节奏的"逗号"，不用塞信息，一两个明确的动态（烟飘/尘浮/雨下）就够，别堆物件。极简/留白场景守"只增强不新增"——不加用户没提的元素。

## 模板 8：动作三帧法（打斗/爆发/召唤等连续动作）

**适用**：任何"连续动作链"（打斗、爆发、召唤），拆成起势→冲击→反应三个独立镜头分别生成，别写成一条连续动作。

```
【起势帧 · [0.5-1s]】攻击方蓄力：[压重心/抬手/握紧]，中景或近景，机位稳定，慢，全身可见。
【冲击帧 · [0.1-0.3s]】只拍接触点（不拍人）：[刀锋相撞的一寸/拳面贴上护甲的一瞬]，特写，50mm 焦段，定格或慢放。
【反应帧 · [1-2s]】受力方受力：[后仰/退步/脱手]，中景，机位稍晃，慢，不写"飞出"。
```

**核心口诀**：冲击帧不拍人、拍接触点——拍两人打 → 崩；拍刀锋撞刀锋的那一寸 → 稳且更有力，同时也更易过审。

## 模板 9：追逐 / 动作戏

**适用**：追赶、跑动、穿越等动作段落。四镜一组，每镜一个主动态。

```
【镜1 · 起跑 · 4s】追逐方启动，低机位仰拍，主体居画面[一侧]，蓄力瞬间。
【镜2 · 穿越 · 5s】主体穿越场景，背景飞掠虚化，跟拍，速度感拉满。
【镜3 · 变向 · 4s】主体急转变向，运动突变，打破匀速。
【镜4 · 逼近/截停 · 5s】逼近或截停，收在落点，给情绪一个停顿。
```

**要点**：逐镜拆、每镜一个动作；中段必须有"运动突变"（变向/变速/景别跳切），纯匀速会平淡。这类是短片里的"节奏抓手"。

## 模板 10：情绪独白 / 氛围人物镜

**适用**：不推进剧情、只落情绪的人物镜头（孤独/沉思/凝望）。

```
[场景包名词1-2个]，[时间段]，[主体]的[景别：近景/特写]，[身体状态：肩膀微塌/目光望向画面外远处/手指无意识地摩挲]，[光线：侧逆光勾轮廓/大片暗部压情绪]，[色调按情绪：冷蓝孤独/暖褐怀旧]，镜头[极缓推近/固定]，大面积负空间，画面锐利清晰，人物结构稳定。
```

**要点**：情绪落在"身体细节 + 光线 + 负空间"上，不用"悲伤""孤独"这种情绪词（模型当噪音）——查 `word-bank.md` 第三部分 C 档情绪词改写表 + 气质词表。

## 模板 11：群像逐次入画（一镜到底）

**适用**：多角色逐个进镜头、末段群像定格的「一镜到底」片型（爆款群像运镜的可复用骨架）。
**先查** `viral-decode.md`：把花名拆成零件后再来填空，别把梗名 / BGM 名写进正文。
**必须配锚图**：尾帧群像图 + 由它 i2i 派生的起幅单人图（见 `shot-continuity.md` 三·补）。

```
【场景】[场景包 2-3 个物件] + [时间段] + [光线来源]
【角色A】[造型写死]  【角色B】[造型写死]
【角色C】[造型写死]  【角色D】[造型写死]
全片共四名角色，各自造型固定不变。
【表情基调】[把抽象气质翻成 3-5 个可见身体语言：眯眼 / 歪头 / 单侧嘴角上扬 / 斜瞟镜头 / 舌尖微吐]
【机位】[焦段] + [景深] + [画幅] + [帧率] + [质感]；稳定器，全程平稳。
【护栏】画面锐利清晰、主体结构稳定不变形、四位角色各自独立完整、镜头运动连贯、画面干净无文字。

全程一镜到底长镜头，摄影机运动与角色走位严格同步。

0-1.5秒：中近景起幅，镜头从左向右平稳弧形环绕，前景与背景出现明显的横向视差。
画面中央只有【A】，微微低头后缓慢抬眼直视镜头；其余角色完全在画外。

1.5-3秒：【B】从镜头极近前景横向走过，[衣摆/皮毛/道具]短暂遮满画面，
形成自然柔和的前景遮挡转场；遮挡过程中焦点稳定、景深连贯。
【B】走过后停在中景主位，与镜头短暂对视。
【A】顺势退到侧后方，把画面主位完整交给【B】。镜头掠过谁，谁才抬眼看镜头。

3-7秒：镜头平滑向后拉远并向左弧形环绕（Dolly out + Arc left），
弧形轨迹带来明显的横向视差与前后层次遮挡，焦点锁定【B】。
【C】从画面右侧走入，停在【B】右后方；【A】停在【B】左后方。
摄影机从【A】与【C】之间缓慢穿过，形成电影纵深。
镜头逐个扫过角色，被扫到的那一位才抬眼看镜头，依次点亮。【D】此时仍在画外。

7-10秒：镜头继续后退并向左轻移，展开为稳定的广角全景。
【D】从远处缓缓走来，停在队伍最远的左后方。
最终形成层次分明的三角梯形站位：【B】画面中央最前方、【A】左后方、
【C】右后方、【D】最远的左后方。
全员只保持极轻微的自然动作。最后 1.5 秒机位完全稳定，
全员[统一视线：斜瞟镜头 / 望向同一远景]定格。

画面锐利清晰、主体结构稳定不变形、四位角色各自独立完整、镜头运动连贯、画面干净无文字。
```

**四条要点**：
1. **每段只引入一个新角色**——最常见的翻车是开场全员同框，梗就没了。
2. **主位要显式交接**（"【A】退到侧后方，把主位完整交给【B】"）；不写，起幅主角会赖在主位不走。
3. **终点站位写进正文只是软约束**，真正兑现靠尾帧锚图；统一视线同理（三·补）。
4. 时序写法按目标模型定：不支持时间戳就把「0-1.5秒」换成「镜头 1」，保留顺序、去掉秒数（四·补）。

**已知边界**：单条 10s 长镜头的弧形环绕视差偏弱，要「扫过一排人」的味道拆两条 5s 拼（四·补）。

## 审核自检（套完模板必过一遍）

- [ ] 无宗教词（神/圣/佛/灵）→ 庄严/优雅/高贵
- [ ] 无法阵/符文/魔法 → 能量阵/光门/发光纹路
- [ ] 无暴力动词+器官（撕+法阵、吼+张口）→ 穿出/仰首
- [ ] 主角色没凑齐某 IP 标志组合（紫黑+红眼+独角）→ 拆 1~2 个
- [ ] 首帧/参考图非真人脸大特写、非 IP 原图
- [ ] 复杂多主体考虑拆镜

详见 `references/audit-avoidance.md`。

## 附录：改写对照表（每次交付必需）

提示词是给模型读的，这一页是**给人读的**。用户看到优化稿时最该知道的不是"改成了什么"，而是"凭什么这么改"——否则优化过程不可审计，用户只能凭成片好坏猜，分歧也无法定位到具体词条。

### 一、交付结构

```
【意图拆解】
- 主诉求（主动词 + 三属性）：…
- 附加偏好（"另外 / 顺便"引出的）：…
- 潜台词 / 节奏意图（第 1.5 步）：…
- 平台与形态约束：…

【改写对照表】
| 原话 / 意图词 | 优化后写法 | 改动类型 | 具体理由 | 原意校验 |
|---|---|---|---|---|

【需你确认】⚠️ 项一句话列出；❌ 项不得出现（出现即回第 1.6 步重改）
```

### 二、字段与枚举

| 字段 | 填什么 |
|---|---|
| **原话 / 意图词** | 用户原句里的词，逐字抄，不美化。主动词一个都不能漏 |
| **优化后写法** | 提示词里对应的实际措辞，可截取片段 |
| **改动类型** | 见下表九类，只填一类；多选时取主要动机 |
| **具体理由** | 因果句：因为模型/平台/审核/方法论上有什么约束，所以换成这个词 |
| **原意校验** | `✅ 增强` / `⚠️ 需确认` / `❌ 降级`，见下 |

**改动类型（九类）**

| 类型 | 含义 | 对应流程 |
|---|---|---|
| `补维` | 补 12 维缺项（主体/场景/光线/景别/色调…） | 第 4 步 |
| `展开` | 动词 → 轨迹 + 路径 + 分段受力结果 | 第 3 步 |
| `意图推断` | 形容词→节奏、主动词→方向性/频率/位形 | 第 1.5 / 1.6 步 |
| `空间锚定` | 角色坐标 → 镜头坐标 | 第 2.5 步 |
| `风格落地` | "电影感/大片感" → 青橙调、anamorphic、胶片颗粒等可渲染词 | 第 4 步 + styles/ |
| `审核规避` | 去血腥、敏感词、真人脸、去 IP 标志组合 | 第 4.6 步 |
| `稳定性护栏` | 写死造型、双手比例、单主动态、防漂移守卫词 | 硬约束 |
| `平台适配` | 时间戳→连续叙事、画幅/时长/模型字段 | 生成前 |
| `删减` | 剥意味词、情绪词、剪辑台指令 | 第 1 / 2 步 |

**原意校验三档（硬闸）**

- `✅ 增强`：细化或展开，方向与强度都未变。
- `⚠️ 需确认`：引入用户没明确的选择（风格倾向、主次分配、画幅、平台假设）→ 表下请用户拍板。
- `❌ 降级`：减弱或丢弃用户已给的**方向、频率、双向性、位形** → 回第 1.6 步重改，**禁止交付**。

### 三、填写规则

1. 最终提示词与对照表**同时给**，不许只吐提示词。
2. 理由必须能回答"为什么这个词比原词更容易被模型执行 / 更容易过审 / 更贴原意"。空话（更专业、更有质感）不算理由。
3. 理由不得是"构图好看""更稳妥""更好出片"这类**与用户意图无关的自利理由**——这类理由一旦落纸，往往正是降级的信号。
4. `⚠️` 项集中列在表下，一句话一个，不藏进表格。
5. 用户可指着任一行说"这行不是我要的"，直接改该行并重跑 lint，不必整稿重写。
