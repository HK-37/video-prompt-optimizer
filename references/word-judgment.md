# word-judgment — 词效判断逻辑（可迁移，不随模型版本过期）

> **这页解决什么**：词那么多，不可能逐词实测，而且实测结论换个模型/升个版本就过期。
> 所以本页不存"某模型某版本的实测档位"，只讲**一把跨模型通用的尺子**——拿到任何词（哪怕没见过的新词），用它一量就知道模型懂不懂、该怎么写。
> **定位**：这是纵轴（内容表达）的"判断逻辑"，是永久资产；`word-bank.md` 的档位是它的应用样例，实测列只是偶尔校准的记录，不追求填满。
> 建立：2026-10-26。外部佐证见文末。

---

## 一、核心尺子：词效 = 词频 × 视觉独义性

一个词模型懂不懂，由两个维度决定（与具体模型无关，是文生视频的底层规律）：

- **词频**：这个词在训练字幕里出现得多不多。多 → 模型见得多、响应稳。
- **视觉独义性**：这个词是否对应**唯一、可见**的画面。独义 → 模型不用猜；多义/抽象 → 模型瞎发挥或当噪音。

两维交叉成四象限，这就是判断任何词的全部依据：

| | 视觉独义（指向唯一可见画面） | 多义 / 抽象（画面不唯一或不可见） |
|---|---|---|
| **高频** | ✅ **稳懂区**：直接用。<br>红色、奔跑、特写、下雨、玻璃、推近 | ⚠️ **翻车区**：模型自由发挥。<br>打、拿、走、看、弄、动、搞、好看 |
| **低频** | 🟡 **展开区**：懂，但要带轨迹展开。<br>抡、劈、攥、瘫、洇、踉跄（文学单字动词） | ❌ **无效区**：模型当噪音。<br>氤氲、苍凉、意境、禅意、高级感 |

**四象限各自的处理法**：
- ✅ **稳懂区**：放心直喂。
- ⚠️ **翻车区（最关键）**：高频但多义，模型会按"最常见解"自由发挥。**必须换成独义的具体词或展开**。这是本 skill 最高频的优化动作。
- 🟡 **展开区**：词对，但低频，单投模型会退化成白话。**带轨迹/路径/受力结果展开用**（见 word-bank 第三部分公式）。
- ❌ **无效区**：抽象意味词，模型根本不渲染。**改写成画面指令**（见 word-bank C 档表）。

## 二、为什么"打"翻车、"砸/劈/砍/压"就行（翻车区详解）

这是最典型的一个。拿尺子一量就清楚：

- **"打"**：高频 ✓，但**极度多义**——打人、打球、打电话、打水、打字、打伞……模型不知道你要哪个"打"的画面，于是按训练里最泛的样本自由发挥，动作变形。落在 ⚠️ 翻车区。
- **"砸/劈/砍/压/捶"**：同样不罕见，但**每个都视觉独义**——"砸"必然是从上往下的重directional、"劈"必然是垂直下切刃口向下、"压"必然是自上而下的持续受力。模型一看就知道手臂怎么动。落在 ✅ 稳懂区。

**规律**：动作词的好坏不看"文不文学"，看**它是否锁定了唯一的肢体轨迹**。
- "动一下"→ 不锁定 → 废
- "抬起右臂"→ 锁定方向 → 好
- "打"→ 不锁定 → 废；"砸"→ 锁定(向下·重) → 好

所以优化动作词的自问句是：**这个词，模型能不能唯一地推出"哪个部位、朝哪个方向、怎么动"？** 不能就换/展开。

## 三、模型通用的三个结构性盲区（和词一样不随版本变）

除了单词，还有三类**写法**模型天然处理不了，其中"空间关系"最常见。这些是训练数据结构决定的，升级也难根治：

1. **相对空间关系 / 角色坐标**：身后、面前、旁边、两侧、对面——模型只认**镜头坐标**（画面深处/前景/左侧入画），不认以角色为参照的方位。根因：训练字幕描述的是"画面里可见什么"，"在某人身后"意味着遮挡、样本稀少。→ 必须翻译成镜头坐标（见 SKILL.md 第 2.5 步）。
2. **否定句**："不要 X / 没有 X"——模型读不懂否定，但"X"这个词照样参与检索，等于反向把 X 招进来。→ 有负向字段走字段，没有就做"否定翻转"写成正向（见 SKILL.md 第 4.5 步）。
3. **抽象情绪 / 意味**：苍凉、孤独、高级感、不易察觉的 X——不可见就不可渲染。→ 翻译成光线/色调/构图/低幅度动作（见 word-bank C 档表）。

这三条和"词频×独义"是一套逻辑的延伸：**凡是"不指向唯一可见画面"的输入，模型都处理不好**——不管它是一个词，还是一种句式。

## 四、怎么自判一个新词（不用测，当场定）

遇到 word-bank 里没有的新词，按这个流程走，30 秒定归属：

1. **可见吗？** 不可见（情绪/意味）→ ❌ 无效区，改写成画面指令。
2. **唯一吗？** 可见但多义（打/拿/弄）→ ⚠️ 翻车区，换独义词或展开。
3. **常见吗？** 可见且独义，但生僻（抡/洇/踉跄）→ 🟡 展开区，带轨迹展开用。
4. 可见、独义、又常见 → ✅ 稳懂区，直接用。

**一句话口诀**：**能不能在脑子里画出唯一一帧？画不出就改，画得出但要蒙就展开，一看就有就直接用。**

## 五、外部佐证（2026-10-26 检索，印证本逻辑非一家之言）

多个独立来源与本页"词频×独义"逻辑一致，说明这是跨模型共识而非单模型经验：

- **具体名词 > 抽象、动作动词 > 状态**（AnimateDiff 原理文，CSDN）：柯基>狗、樱花树>树、跳跃>"在空中"、融化>"变成液体"。原因原话——"具体 Token 给模型的信息量更大，更容易找到对应视觉特征"，即本页的"视觉独义性"。
- **通用形容词是"高频弥散标签"**（Higgsfield prompt skill）："beautiful/stunning/epic/cinematic/dynamic"要删或替换成**具名的导演/布光/镜头规格**——"generic adjectives are high-frequency labels spread across a huge diffuse slice of training data, so they pull the output toward nothing in particular"。这正是本页 ⚠️ 翻车区（高频+多义=拉向平庸）的英文版表述。
- **用可见动作动词、别用抽象情绪**（Frameo / DEV / NeurAITool）："walking/pouring/looking up" 优于 "feeling inspired/being productive"；"pours/sprints/flickers" 优于 "beautiful/dynamic"。
- **一镜一动作、一镜一运镜、空间要显式、否定翻正向**：多篇 2026 指南一致——与本页第三节三大盲区、SKILL.md 硬约束完全对齐。

> 结论：本逻辑有外部共识支撑。但**这些来源给的是"原则"，不是"某模型的实测分数"**——正是我们要的"可迁移逻辑、非实测快照"。

## 六、与实测的关系（实测降级为"校准"，不追全量）

- 本页逻辑是**第一判据**：绝大多数词用尺子一量就定，不用烧积分。
- 实测只在两种情况做，且只为**校准尺子**，不为填表：
  1. 逻辑判断拿不准某词落哪象限；
  2. 某次出片明显翻车、与逻辑预期不符 → 抽测定位，回填一条校准记录到 word-bank 对应词的"实测"列。
- **word-bank 的"实测"列没填 ≠ 没做完**。它是"偶尔校准的留痕"，不是"必须全测的待办"。
