# 内容审核规避手册（视频/图像生成）

> 用途：生成前 / 生成被拦时查阅。**审核不是"效果差"，是"直接不出片"，且已扣费的最伤。**

> ⚠️ **实测基线（关键，读前先看）**：下列拦截结论来自 **2026-10（约 10-19~10-27）** 一轮机甲双塔案例实测复盘（即梦图生图 + 图生视频，具体模型版本当时未记录，视为"2026-10 期在用版本"），累计数十次拦截沉淀。**审核规则随平台版本持续调整——今天必拦的词下个版本可能放开，反之亦然。** 因此：① 本手册所有"必拦/偶发/不敏感"的判断都是**该时间点该版本的经验**，不是永久事实；② 实际使用以接口真实反馈为准，被拦/没被拦都以当次为准，不拿本表硬顶；③ 发现与本表不符，说明规则变了——按 STRUCTURE「实测结论记录规范」追加一条带**新日期+版本**的更新，不要直接抹掉旧结论（留着能对比"何时变的"）。

## 零、先分清拦截阶段与真实原因（最关键，混了就永远改不对）

| 错误码 | 中文含义 | 判定时机 | 是否扣费 | 拦的是什么 |
|---|---|---|---|---|
| **20111** | 输入内容不合规 | 提交时**秒拒** | 基本不扣 | 提示词里的**敏感词** |
| **10940** | 常见通用包装码，可能包版权、输入图或其他错误 | **必须读 `error.message`** | **按当次返回记录，不预设扣费** | 不能只看 code 判断 |
| **PrivacyInformation** | 输入图疑似真人 | 提交图时判 | 以当次返回为准；本轮输入创建失败无 usage | 输入图里的**疑似真实人脸** |

**决策铁律**：
- 拿到 **20111** → 这是**词**的问题，换措辞、删敏感词。
- 拿到 **10940** → **先读完整 message**。若真实原因是输出画面像已有 IP，换同义词无效，必须改视觉特征；若是输入图、渠道路由或其他原因，按该原因处理，不能一律改画。
- 拿到 **PrivacyInformation** → 调整合规输入图，或对同一合规图换目标渠道实测；先登记输入审核结果，不把图片派生成功等同于视频链可用。

> 判断口诀：**20111 改词，输出侵权改画，输入图改图或换合规渠道，所有包装码先读 message。**

## 一、版权审核（10940）——画面像已有 IP

### 1.1 为什么会触发

10940 不是关键词过滤，是**生成出的画面与已知 IP 的相似度判定**。所以：
- 提示词里**完全没提 IP 名**，照样可能被拦——只要画出来像。
- 换同义词、换语序、加"原创"字样——**全部无效**，因为判定对象是画面不是文字。

### 1.2 高频踩雷的"IP 特征组合"（实测被拦）

| IP 相似方向 | 触发特征组合 | 实测案例 |
|---|---|---|
| EVA 初号机 | 紫黑配色 + 赤红发光双眼 + 独角/尖角 + 生物感装甲 + 瘦长人形 | ShotB 独角版、红机甲紫黑版多次 10940 |
| 泛机甲 IP | 双人黑风衣 + 巨型机甲 + 魔法阵 同框 | 12s 三段式测试 10940 |

**规律**：单看每个特征都不侵权，但**几个标志性特征同时出现**就会命中。破相似度的关键是**去掉其中 1~2 个标志性部件**。

### 1.3 去 IP 化替换表（实测有效，A/B 两版全过）

| 高危视觉特征 | 安全替代 | 说明 |
|---|---|---|
| 紫黑配色 | 银灰 / 深灰工业合金 | 配色是最强的 IP 指纹之一，优先改 |
| 赤红发光双眼 | 暗橙 / 橙色眼带 | 红眼+尖角=EVA 最强组合，必须拆 |
| 独角 / 光秃双尖角 | 光洁无角头盔 **或** 机械棱面角冠 | 要"有角"就做**带分件结构线的机械角**（棱面、倒角、接缝），不要动物式光角 |
| 魔法阵 / 符文 / 电弧 | 能量光门 / 同心圆能量环 / 光晕 / 发光纹路 | 魔法语义既触发版权也触发宗教/迷信词 |
| 生物装甲 / 有机装甲 | 工业外骨骼 / 机械分件装甲 | "生物"二字也易触宗教/恐怖联想 |
| 獠牙 / 尖牙 / 血口 | 无（直接删） | 兽性用姿态表达，不用器官 |

### 1.4 三条实用过审策略

1. **首尾帧锁图**：把定稿图当首/尾帧，画面被图锁住、描述词影响力变小，过审率高于纯文生。要求精确造型时必用。
2. **参考图绝不直接用 IP 原图**：拿 IP 截图做 i2i 参考会 20111/10940。参考图只用来**人工提取动作语言**（姿态、构图、运镜），再用**文字**重新描述——不把图喂给模型。
3. **阵发性重试**：同一提示词有 fail/success 交替的波动（实测失败率 0%~80% 剧烈波动）。被拦先**原样重试 1~2 次**，再考虑改方案，别急着推翻。

**两条通用补充（2026-10-27 实拍复验）**：

4. **参考图本身高危，做首尾帧同样会 10940**——不只文生会。若参考图自身凑齐某知名 IP 的标志特征组合，把它喂成首帧时，那组特征会被"焊"进输出画面，文字去 IP 化无效（判的是画面不是文字）。对策：先拆图（去掉 1~2 个标志特征）再当首帧，或靠第 3 条的重试碰阵发波动。
5. **seedance 带首帧图生成时，不传 `ratio`**——输出比例强制跟随首帧图，手动指定 ratio 会报 `InvalidParameter.TaskTypeConstraint`（任务直接失败，非审核拦截）。带首帧时只留 `resolution`/`duration`/`watermark`。（实测 2026-10-27，seedance 2.5，经网关调用；版本精确号未记录）

## 二、宗教 / 迷信词审核（20111）

| 敏感词 | 触发场景 | 替代 |
|---|---|---|
| 神圣、神性、神、圣洁、神祇、神明 | 即梦 i2i 必拦（20111） | 庄严、优雅、高贵、肃穆、沉静 |
| 天使、圣光、圣域、圣洁光环 | i2i（疑似） | 光翼、能量翼、机械翼、泛光 |
| 佛、菩萨、灵体、魂魄、诅咒、祭祀、献祭 | 多模式（迷信/宗教） | 删；或改中性词（灵体→虚影，诅咒→束缚） |
| 魔法、法术、符咒、咒语、法阵（宗教语境） | 多模式 | 能量、力场、能量环、光门 |

**规则**：宗教词一律换成**气质词**——保留"庄严/神圣"的情绪意图，但用"庄严/肃穆/高贵"这类可视觉化的气质词，不出现宗教实体。

**灵敏度与模式相关**（实测）：宗教词在即梦 **t2i 下不一定敏感，i2i 下必拦**。图生图尤其要清干净。

## 三、暴力 / 动作词审核（20111）

| 敏感写法 | 触发 | 替代 |
|---|---|---|
| 撕开、撕裂、扯开、抓穿（+法阵/屏障） | 20111 | 穿出、撑开、步出、跨出、浮现 |
| 嘶吼、怒吼、长啸、咆哮（+张口/咧嘴） | 20111 | 仰望、扬首、神情凌厉、气势逼人、无声扬头 |
| 神情狰狞、凶恶、暴虐 | 20111 | 神情冷峻、专注、肃杀、压迫感 |
| 血、血腥、伤口、刺穿、血浆 | 20111 | 删；力度改用姿态/光影表达 |
| 斩、砍（武侠/动作戏高频） | 偶发 20111（阵发） | 风险词但**非必拦**——武侠刚需动作，lint 不再兜底扣分；真被拦时力度改用姿态/光影 |

**规律**：**"激烈动作 + 攻击性器官动作"** 的组合最容易踩线。要表达"狂/猛"，改用**姿态（佝偻、弓背、蓄势）+ 光影（逆光、硬边、高对比）+ 景别（低角度仰拍）**，比动词安全得多。

## 四、真人脸审核（PrivacyInformation）

**现象**：图生视频用【人脸特写】关键帧做首帧，被判"疑似真人"（`InputImageSensitiveContentDetected.PrivacyInformation`），任务失败。

**判定规律（实测）**：
- **脸部大特写** → 必触发
- 双人中景 / 全身远景 / 背影 / 剪影 → 不触发

### 2026-11-13 更新：声明、图像特征与渠道差异

本轮原创虚构人物实测：同一张写实精修人像、同一句「AI 生成原创虚构角色、非现实真人照片」声明，在 seedance 2.5 首次及原样重试均返回 `PrivacyInformation`，在 MiniMax H3 同图同声明成功创建；卡通大头人像在 seedance 2.5 成功创建。

- **AI 生成声明不是过审保证**，只能作为准确的素材来源标注；不得把现实真人照片伪装成 AI 生成图。
- 图像写实程度与渠道封装都可能影响结果；单次现象不证明因果，更不能写成「卡通化必过」「H3 对写实人像必过」。
- 可对**同一合规输入**换渠道做一次明确记录的实测；不要反复原样重试或靠修改图伪装绕审。
- 输入审核失败与输出生成失败分别记录；以当次返回的 usage/费用为准，不能把输入创建失败按成功视频计费。

**规避方案**：
1. 人物镜头优先用**背影 / 侧影 / 剪影 / 远景小人**，看不清五官就不触发——而且背影施法剪影氛围往往更好（实测：背影版比正脸版更美更神秘）。
2. 需要正脸的，改成**中景及以上**（不推大特写）。
3. 戴头盔 / 面罩 / 帽檐压阴影，遮住五官。

## 五、审核定位法（二分排查）

不知道哪个词触发时，用二分法锁定：

1. **保持主体不变，只留最简描述**跑一次 → 若过：说明主体没问题，问题在附加描述。
2. **加回一半描述**跑一次 → 过/不过 缩小范围。
3. 逐词回加，直到失败 → 锁定触发词。
4. 锁定的词按上表替换，**其他部分不动**验证替换有效。

**原则**：每次只改一个变量，否则永远不知道是哪个改动生效/失效。

## 六、生成前自检清单（写提示词时就过一遍）

写完提示词、提交前，按这 6 条扫一遍：

- [ ] 有没有**宗教实体词**（神/圣/佛/灵/咒）？→ 换气质词
- [ ] 有没有**魔法/迷信词**（法阵/符文/魔法/祭祀）？→ 换能量/力场/光门
- [ ] 有没有**暴力动词 + 攻击器官**组合（撕+法阵、吼+张口）？→ 换姿态表达
- [ ] 主角色的**视觉特征**是否凑齐了某个知名 IP 的标志组合（配色+标志部件+体型）？→ 拆掉 1~2 个
- [ ] 首帧/参考图是不是**真人脸特写**或 **IP 原图**？→ 改背影 / 换原创 / 用文字转述
- [ ] 是不是**复杂多主体同框**（易整体被判侵权）？→ 考虑拆镜

**六条全过，再提交。** 能省下大量"生成完才发现被拦、积分白扣"的浪费。

## 七、成本提醒

- **20111**：提交秒拒，基本不亏。
- **10940 / 真人脸**：早期案例出现**生成完成后才判、已扣费**，是最贵的坑；但这不是所有拦截的统一时序。输入图在创建阶段被拒时，可能没有 usage 或成片费用，必须按当次返回记录，不得一律写成「已扣费」。
- 长视频（30s）里内容多，**单点踩线整条报废**。复杂主体宁可拆段（每段 5~15s），一段被拦只损失一段。
