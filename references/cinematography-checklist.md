# 镜头语言补全清单（10 维）

> 用途：转写第 4 步"补镜头"时逐维检查。**用户已写的维度不覆盖，缺失的按本表补默认值。**
> 原则：每维只写一个值，宁可少写不要堆砌——镜头词堆太多会互相打架。

---

## 十二个维度

### 1. 景别（必补）

| 值 | 适用 |
|---|---|
| 大远景 | 环境压人、孤独感、史诗感 |
| 全景 | 交代人物与环境关系 |
| 中景（腰部以上） | 人物动作戏默认值 |
| 中近景（胸部以上） | 对话、轻微情绪 |
| 近景/特写 | 表情、手部细节、情绪高点 |
| 大特写（眼/嘴/物件局部） | 关键意象，须由运镜推到，别直接开场 |

**默认**：人物动作→中景；表情戏→中近景；空镜→全景或大远景。

> **总纲：景别 = 情绪刻度，不是"拍得全不全"。** 越近越逼观众共情（特写=强制看情绪），越远越疏离、越让人渺小（大远景=命运感/孤独）。选景别先问"这段想让观众感到什么距离感",再定远近——而不是单纯为了"交代清楚"。

### 2. 机位角度（选补）

| 值 | 效果 |
|---|---|
| 平视 | 中性、纪实（默认） |
| 低角度仰拍 | 主体显得高大、有压迫感 |
| 高角度俯拍 | 主体显得弱小；大俯拍=上帝视角 |
| 过肩 | 双人对话、对峙 |
| 荷兰角 dutch | 画面倾斜、地平线歪 | 失衡、疯狂、不安、迷幻 |
| 鸟瞰/顶拍 bird's-eye / overhead | 正上方垂直向下 | 上帝视角、格局/图案、宿命俯视、尸体/餐桌俯拍 |
| 虫视 worm's-eye | 极低贴地向上 | 极致压迫、仰望庞然、英雄登场 |
| 主观视角 POV / first-person | 代入角色眼睛所见 | 沉浸、代入、惊悚追逐（长段晃动易引发眩晕，慎用） |
| 地平视角 ground level | 相机贴地面 | 脚步、尘土、动物视角、紧张潜行 |

**默认**：平视。写强弱关系时才动它：强者仰拍、弱者俯拍。荷兰角专治"事情不对劲"，鸟瞰专治"命运/全局感"，是两张高表现力牌。

### 3. 运镜（必补，一次只一种）

| 值 | 适用 |
|---|---|
| 固定机位 | 人物动作默认值，最稳 |
| 缓慢推近 | 情绪聚焦、紧张积累 |
| 缓慢拉远 | 揭示环境、抽离感、结尾 |
| 横向平移 | 空镜、街景、跟随行走 |
| 跟随（背后/侧面） | 移动主体 |
| 手持轻微晃动 | 纪实感、不安感 |

**默认**：人物动作→固定机位；空镜→缓慢平移；情绪特写→缓慢推近。
**多段运镜必须合并为单一连续路径**，终点写"停住"。

> **总纲：运镜没有"中性"的——镜头一动就在表态。** 推近=聚焦/逼近情绪，拉远=抽离/交代处境/渺小，横移=旁观/展开，手持晃=不安/临场，升降=格局/命运。所以运镜要**服务这段的情绪意图**，不是"让画面别太死"就随手加一个。拿不准时，固定机位＞乱加运镜——静止本身也是一种有力的表态。

**高表现力运镜（精选，强戏才用，一条里最多一个）**：

| 运镜 | 长啥样 | 适用 / 注意 |
|---|---|---|
| 希区柯克变焦 dolly zoom | 推轨前进同时变焦拉远（反之亦然），背景诡异胀缩、主体不变 | 眩晕、顿悟、天塌、恐惧瞬间。极强，一片用一次 |
| 弧形环绕 arc / orbit | 相机绕主体画弧或整圈 | 对峙、揭示、高光时刻、强调人物 |
| 甩镜 whip pan | 极快横摇拉出残影 | 转场、暴力衔接、能量爆发 |
| 升降 crane / jib | 垂直升起或降下，常收于大全景 | 开场建立、结尾抽离、史诗收束 |
| 穿越 pass through | 相机穿过门/窗/缝隙进入下一空间 | 一镜到底的空间转换、沉浸 |
| FPV 俯冲 | 无人机式高速贴地/穿物飞行 | 动感、空间炫技、追逐 |
| 跟拍长镜 tracking oner | 持续跟随主体不切镜（接维度10长镜头） | 沉浸、真实时间、节奏戏 |

> 这些是从 melies 86 条镜头运动里**挑出的高表现力少数**，不是全量。基础推拉摇移已在上表，够日常用。两张最通用的高价值牌：**跟拍长镜**（节奏沉浸）和**弧形环绕**（对峙张力）。

**动作戏/打斗运镜四原则**（连续动作段，落到每个镜头都要守，否则崩脸/肢体粘连/兵器变面条）：

| # | 原则 | 落地 |
|---|---|---|
| 1 | **镜头动 / 人静** | 镜头动→人可以静；人动→镜头必须静。**两者只能一个在动**。想要速度感，让镜头高速（贴地俯冲、甩镜），人保持静止或单点微动，速度感还在、崩脸风险没了 |
| 2 | **一招一镜** | 一个镜头只允许**一个接触点**（一次相碰/命中/格挡）。连续三招写进一条，模型会脑补中间过程——那部分就是崩的 |
| 3 | **用特写代替全景** | 全景=两人全身+兵器+背景，信息量爆炸必崩。**优先顺序：接触点特写 > 兵器特写 > 面部 > 半身 > 全身**，能不拍全身就不拍 |
| 4 | **减速锚点** | 专业运镜不靠"持续高速"，靠"加速→瞬间减速/定格→再释放"。凡写"高速/快速/连续"的，换成**一个减速锚点**（定格/悬停/极短时长）。没有减速锚点的打斗 prompt，一定崩 |

> 补充一条：最抓人的常**不是打起来那一下，是打起来前那半秒**——持械对峙、刀尖下压、喉结滚动，静止、安全、张力最大（对应 shot-continuity 的"隔空间对峙"）。动作戏别一味求快，留白的前摇才是张力所在。

### 4. 构图（选补，情绪场景建议必补）

| 值 | 效果 |
|---|---|
| 中心构图 | 稳定、正面、仪式感 |
| 三分法（主体在左/右三分线） | 通用舒适（默认） |
| 大面积负空间 + 主体居边缘 | 孤独、渺小 |
| 对称构图 | 秩序感、诡异感（韦斯·安德森/库布里克） |
| 前景遮挡（枝叶/门框/窗沿） | 窥视感、纵深 |
| 低地平线（天空占 2/3） | 开阔、命运感 |
| 引导线 leading lines | 路/栏杆/光束把视线引向主体 | 纵深、聚焦、宿命指向 |
| 框中框 frame within frame | 用门/窗/镜/拱把主体再框一层 | 窥视、囚困、层次、偷窥感 |
| 一点透视/消失点 vanishing point | 线条汇聚于一点，强对称纵深 | 库布里克式、压迫、秩序、无尽走廊 |
| 三角构图 triangular | 主体排布成稳定三角 | 群像稳定、权力结构、古典均衡 |
| 层次纵深 layered depth | 前景/中景/背景三层叠出空间 | 真实感、信息密度、沉浸 |
| 倒影 reflections | 水面/镜面/玻璃映出主体 | 双重性、诗意、虚实 |
| 窥视视角 voyeur | 透过缝隙/遮挡偷看的构图 | 偷窥、监视、紧张、不安 |

**默认**：三分法。情绪词改写时优先从这里取（孤独→负空间+边缘）。想要"高级感构图"时，框中框和一点透视是两张立竿见影的牌。

**注意力管理（构图法则之上的一层：怎么控制"观众先看哪、看不看得清"）**：

- **最高对比处 = 视觉焦点**。画面里明暗/色彩对比最强的地方最抢眼——不是放在中间的就是焦点。一扇亮窗会比暗处的人脸更抢视线。写提示词时让**焦点落在最强对比处**（"只有脸被照亮、周围压暗"），或主动压掉会抢戏的干扰亮区。
- **视觉重量**：大小、明暗、饱和、位置都有"重量"——大的/亮的/艳的/孤立的更重。平衡 ≠ 对称：非对称的重量配置（一个重主体 + 大片留白）制造张力和动感，比对称更有劲。
- **焦点层级**（借自概念设计）：把"最强对比、最锐边缘、最丰富色彩、最具体纹理"**全留给焦点**；次要区域主动留糊、留简、降对比。提示词里"主体锐利清晰、背景虚成光斑/柔焦"就是这个——给模型明确的主次。
- **大气透视（远近分层）**：越远越**浅、越冷、越低对比、细节越少**，雾/霾随距离递增。要纵深就写"近景深色锐利、远景泛青灰模糊"，比只写"有纵深"有效。
- **looking room（视线留白）**：人物看向/走向的那侧留出空间，画面才不憋。

### 5. 光线方向与质感（必补）

| 值 | 效果 |
|---|---|
| 侧光 | 立体感、明暗分割（默认） |
| 逆光/侧逆光 | 轮廓光、剪影、神圣或神秘 |
| 顶光 | 眼窝阴影、压抑审讯感 |
| 底光（火光/屏幕光从下往上） | 不安、诡异 |
| 柔光（阴天/窗纱） | 温和、日常 |
| 硬光（正午/探照灯） | 锐利、戏剧性 |

**默认**：侧光。光线要有**来源**（窗、灯、火、月），别只写"侧光"——写"灶膛火光从左侧照亮半张脸"。

> **motivated lighting 原则（光要可信）**：好的打光都像来自画面内某个合理光源。先定"光从哪个具体光源来"（窗/灯/火/霓虹/月），再让光的**方向、色温、软硬**都对齐那个来源——而不是凭空给个"侧光"。AI 生成同理：写"冷白月光从左侧窗斜照进来"比写"侧光"可信得多，因为模型能顺着"月光+窗"推出合理的方向、色温和质感。

**布光法专名（想要"专业打光感"时点名，模型认这些词）**：

| 布光法 | 打在哪 / 长啥样 | 适用 |
|---|---|---|
| 三点布光 three-point | 主光+补光+轮廓光标准组合，立体干净 | 对话、采访、标准人像的安全底 |
| 伦勃朗光 Rembrandt | 侧 45°，暗侧颊上留一个三角形光斑 | 古典肖像、沉稳、有份量的人物 |
| 蝴蝶光 butterfly | 正前方高位下打，鼻下一个蝴蝶形阴影 | 魅力人像、女性面部、时尚感 |
| 分割光 split | 光只照半张脸，另一半没入黑 | 内心分裂、善恶两面、强戏剧 |
| 轮廓光/边缘光 rim/kicker | 从后侧勾出主体发丝与肩线的亮边 | 主体从暗背景里剥离、神秘、高级感 |
| 剪影 silhouette | 只留主体黑色外形，背景亮 | 悬念、匿名威胁、唯美留白 |
| 明暗对比 chiaroscuro | 大面积暗 + 局部强光，油画式 | 黑色电影、宗教感、低调戏剧 |
| 实用光 practical | 画面内可见的真实光源（台灯、霓虹、烛火）自身发光 | 真实感、氛围、夜戏定调 |
| 动机光 motivated | 人造布光但伪装成某个画面内光源的延伸 | 看着自然又可控，叙事打光默认思路 |

**光源 / 时刻（给"什么时间、什么光"的定调词）**：

| 值 | 效果 | 适用 |
|---|---|---|
| 黄金时刻 golden hour | 日出日落暖金低斜光、长影 | 温暖、怀旧、浪漫、希望 |
| 蓝调时刻 blue hour | 日落后天光幽蓝、尚未全黑 | 孤独、过渡、静谧、城市苏醒前 |
| 烛光 candlelight | 暖橙、微晃、近距离衰减快 | 亲密、古典、脆弱 |
| 霓虹实用光 neon practical | 彩色霓虹招牌当光源，赛博/港风 | 夜城、暧昧、风格化 |
| 窗光 window light | 柔和方向光从窗进入，带窗格影 | 室内自然、安静、日常 |
| 体积光/丁达尔 volumetric | 光束穿过烟尘雾显出可见光柱 | 神圣、氛围、空间纵深（见维度11氛围） |
| 斑驳光 dappled | 透过树叶/百叶的碎光斑 | 斑驳树荫、慵懒、不安的切割感 |
| 高调 high-key | 整体明亮、阴影极淡 | 轻快、梦幻、广告、喜剧 |
| 低调 low-key | 整体暗、大片阴影主导 | 压抑、悬疑、惊悚、黑色电影 |

### 6. 光比与明暗对比（选补，夜景/情绪戏建议必补）

| 值 | 效果 |
|---|---|
| 高对比（亮部很亮暗部死黑） | 戏剧性、黑色电影、紧张 |
| 低对比（整体柔和过渡） | 日常、温和、回忆 |
| 明暗分区（人亮景暗 / 人暗景亮） | 主体分离、剪影 |

**默认**：白天→低对比；夜景→高对比。
**写法上给"亮部在哪、暗部在哪"**，比"高对比"三个字更有效：如"只有脸被油灯照亮，身后全黑"。

**光比量化梯度（想精确说"多强的对比"时用，比"高/低对比"准）**：光比 = 亮侧 : 暗侧的亮度比。行业用它把对比变成可精确说的数字：

| 光比 | 观感 | 适用 |
|---|---|---|
| 2:1 | 很柔、亮、影浅 | 情景喜剧、广告、美妆、晨间、温馨日常 |
| 4:1 | 适中、有立体感 | 叙事剧标准、纪录片、多数正常戏 |
| 8:1 | 深沉、暗部压下去 | 犯罪/惊悚剧、悬疑、有份量的情绪戏 |
| 16:1~32:1 | 极端、暗部近死黑 | 黑色电影、恐怖、neo-noir、强 chiaroscuro |

> 用法：用户要"犯罪片那种压抑感"→写"约 8:1 光比，暗部沉下去"，比"高对比"精确。高戏剧题材（神性/狂暴、犯罪、悬疑）适合 8:1 起步。

### 7. 色调与对比度（必补）

| 值 | 适用 |
|---|---|
| 暖黄低色温 | 温馨、怀旧、灯下 |
| 冷蓝 | 夜、孤独、疏离 |
| 冷暖对比（暖主体冷环境） | 人情 vs 环境，雨夜便利店模式 |
| 低饱和灰调 | 压抑、纪实、年代感 |
| 高饱和单色主导（紫/红/绿光源） | 风格化、超现实 |
| 黑白灰水墨 | 古典、留白 |

**默认**：按场景时间走——白天自然色、黄昏暖黄、夜景冷蓝。

**色温 K 值（想精确说"多暖/多冷"时用）**：暖冷不只是"暖黄/冷蓝"，可用开尔文值精确给——钨丝灯/烛火 ≈ 3200K（暖橙）、日出日落 ≈ 3500-4500K、正午日光/中性 ≈ 5000-5600K、阴天/荫影/月光 ≈ 6500-7500K+（冷蓝）。暖=舒适/怀旧/亲密，冷=神秘/疏离/严肃。写"约 3200K 暖光"比"暖色"更能锁住色温方向。

> **情绪/风格/多镜色彩怎么设计**（color script 全片色彩弧、色彩心理对照、和谐配色方案、橙青为何有效+何时避开、限制调色板）见 `references/color-design.md`——那是色彩的"为什么和怎么规划"，本维是"单镜选什么色"。

**调色法专名（想要某种"片子的色"时点名）**：

| 调色法 | 长啥样 | 适用 |
|---|---|---|
| 青橙调 teal & orange | 肤色压暖橙、暗部/环境推青，好莱坞大片默认 | 商业感、动作、冷暖对比强 |
| 漂白 bleach bypass | 去银、低饱和高反差、发灰发硬 | 战争、冷酷、纪实、绝望 |
| 单色 monochrome | 单一色相铺满（不止黑白，可全蓝/全红） | 风格化、纯粹、主观情绪 |
| 棕褐 sepia | 暖棕做旧 | 回忆、历史、泛黄老照片 |
| 去饱和 desaturation | 整体抽掉颜色接近灰 | 压抑、冷峻、末世、纪实 |
| 高饱和 hyper-saturation | 颜色推到极浓艳 | 梦境、广告、超现实、糖果色 |
| 褪色胶片 filmic faded | 黑位抬灰、对比柔、复古胶片 | 文艺、怀旧、温柔 |
| 交叉冲印 cross process | 偏色诡异（青绿高光/品红暗部） | 迷幻、躁动、MV 感 |
| 夜景日拍 day for night | 白天拍压成冷蓝假装夜晚 | 夜戏但要清晰细节 |
| 月光蓝 moonlight gel | 冷蓝布光模拟月光 | 夜晚室外、静谧、清冷 |
| 分离调色 split toning | 高光一色暗部另一色（如暖高光冷暗部） | 精细氛围、冷暖分层 |
| 复古 vintage | 综合做旧（褪色+颗粒+偏色） | 年代感、胶片质感 |

**默认**：不点名则走上面六种基础色调。青橙调是最"电影感"的万金油但也最烂大街，追求差异化、不想撞大众色时反而建议避开，走褪色胶片或分离调色。

### 8. 景深（选补）

| 值 | 效果 |
|---|---|
| 浅景深（背景虚化） | 聚焦主体、情绪特写 |
| 深景深（前后全清晰） | 交代环境、调度戏 |
| 前实后虚 → 焦点转移 | 两个主体间的注意力引导（高级技巧，慎用） |

**默认**：特写→浅景深；全景→深景深；中景不写（交给模型）。

### 9. 焦段 / 镜头（选补，强表现力时建议必补）

> 焦段决定"空间被压缩还是被拉开"——这是镜头语言里最被忽视、却最影响质感的一维。广角＝夸张纵深+边缘变形（张力、压迫、主观），长焦＝压缩空间+背景贴近（宿命感、窥视、人潮中的孤立）。

| 值 | 视觉效果 | 适用场景 |
|---|---|---|
| 广角 14–24mm | 夸张透视、纵深拉长、边缘膨胀变形 | 狭小空间显大、压迫感、主观冲入、环境交代 |
| 标准 35–50mm | 接近人眼、无明显畸变 | 写实叙事、对话、默认选择 |
| 中长焦 85mm | 轻压缩、人像背景柔化 | 情绪特写、人物肖像 |
| 长焦 135–200mm | 强压缩空间、背景拉近贴紧主体、极浅景深 | 宿命感、人潮中孤立、窥视/偷拍感、远距离对峙 |
| 变形宽银幕 anamorphic | 2.39:1 宽幅、水平镜头光晕、椭圆散景 | 史诗感、电影质感、科幻 |
| 鱼眼 fisheye | 极端桶形畸变、圆形视野 | 迷幻、主观失衡、风格化 |
| 移轴 tilt-shift | 选择性对焦、微缩模型感 | 俯瞰城市如玩具、超现实 |
| 微距 macro | 极近距离、极浅景深放大细节 | 器物质感、昆虫/水珠、开场空镜 |

**默认**：不指定则不写（交给模型按景别推断）。**长焦压缩**和**广角压迫**是两张最高价值的牌——想要"人潮中一个人的孤独"用长焦，想要"空间吞人"用广角。

### 10. 时间与运动（选补，节奏戏建议必补）

> 这一维管的是"时间怎么流"——镜头节奏的一半靠运镜，一半靠这里。慢下来放大情绪，变速制造冲击，一镜到底给沉浸。

| 值 | 视觉效果 | 适用场景 |
|---|---|---|
| 慢动作 slow motion | 时间拉长、动作细节凝滞 | 情绪高点、暴力美学、水花/碎片/发丝 |
| 变速 speed ramp | 实时→慢镜或慢→快的速度突变 | 动作爆发瞬间、打击感、转场冲击 |
| 冻结帧 freeze frame | 画面定格一瞬 | 强调、章节收尾、宿命定格 |
| 子弹时间 bullet time | 时间近乎静止、机位绕主体环动 | 高潮炫技、超现实对峙 |
| 延时 timelapse | 时间极度压缩、云走日移 | 时间流逝、城市苏醒、环境交代 |
| 长镜头 oner / long take | 单镜不剪贯穿一整段 | 沉浸、调度炫技、一气呵成的紧张感 |

**默认**：不指定则默认实时速度，不写。**慢动作用在情绪或暴力的最高点**（全程慢＝廉价 MV 感），**长镜头**契合追求沉浸、不打断时间流的节奏——但对 AI 生成是难点，优先用在单一动作段落而非复杂调度。

### 11. 机内/光学效果（选补，定质感时用）

> 这一维是"镜头和胶片本身留下的痕迹"——决定画面像数码还是胶片、像监控还是电影。少量点缀提质感，堆满就脏。

| 效果 | 长啥样 | 适用 / 注意 |
|---|---|---|
| 镜头光晕 lens flare | 强光入镜拉出光斑光条 | 逆光、希望感、临场真实。别滥用 |
| 变形光晕 anamorphic flare | 水平蓝色长条光晕 | 科幻、电影宽银幕质感 |
| 光晕溢出 halation | 高光边缘泛红光渗 | 胶片感、复古、柔和梦幻 |
| 胶片颗粒 film grain | 画面浮动细颗粒 | 胶片质感、年代、去数码感（追求风格化质感可常备） |
| 散景 bokeh | 背景光点化成柔圆光斑 | 浅景深氛围、夜景灯火、浪漫 |
| 二次曝光 double exposure | 两画面叠印 | 回忆、心理、诗意转场 |
| 焦点转移 rack focus | 焦点在前后景间移动 | 引导注意力、揭示、两主体关系（接景深维度） |
| 强迫透视 forced perspective | 利用透视错觉改变大小关系 | 巨物/渺小的错觉、超现实 |
| 晕影 vignette | 四角压暗 | 聚焦中心、复古、窥视、老镜头 |

**默认**：不点名则不加。颗粒+光晕溢出是做"胶片质感/风格化印记"最省力的组合；散景几乎是浅景深夜景的标配。记住**机内效果是调味，不是主菜**，一条里最多挂一两个。

### 12. 氛围介质（选补，定环境情绪时用）

> 空气里的东西——雾、尘、烟、雨。它们既给氛围，又给光一个"可见的载体"（光束要靠介质才看得见）。雨雾烟雪的**动态词**在 word-bank 环境动态里，这里管的是"介质作为氛围"的整体写法。

| 介质 | 长啥样 | 适用 |
|---|---|---|
| 丁达尔/体积光 volumetric | 光束穿雾/尘显出实体光柱 | 神圣、纵深、教堂/森林/窗边，最出氛围 |
| 浮尘 floating dust | 空气里飘的微尘，逆光下可见 | 废墟、老屋、时间停滞、荒凉 |
| 薄雾 mist / haze | 空气发灰、远景柔化、层次拉开 | 清晨、忧郁、朦胧、神秘 |
| 浓雾 fog | 能见度低、吞没背景 | 悬疑、未知、恐怖、孤立 |
| 烟 smoke | 缭绕流动的烟 | 战场、酒吧、仪式、危险 |
| 雨 rain | 雨丝+地面反光+水花 | 情绪、宿命、冲突、净化（夜雨霓虹是经典） |
| 水下 underwater | 光在水中摇曳、悬浮粒子、蓝绿调 | 梦境、窒息、潜意识、唯美 |

**默认**：不点名则空气透明不写。**体积光是性价比最高的氛围牌**——只要有光源+一点介质（雾/尘/烟），画面立刻从"平"变"有空气"。做氛围短片这张几乎必用。

## 使用规则

1. **必补维度**（景别/运镜/光线/色调）缺一不可；**选补维度**（角度/构图/光比/景深/焦段/时间运动/机内效果/氛围介质）按场景类型表决定。焦段和时间运动虽属选补，但它们是电影感的强表现力维度——节奏戏、情绪戏、要"镜头语言"时主动补；机内效果和氛围介质负责画面质感与空气感，氛围戏、强风格片主动补（强风格先查 `styles/`）。
2. 用户原文已指定的维度**保留不覆盖**，只做词汇规范化（"镜头怼脸"→"大特写"）。
3. 每维**一个值**。两个值相互冲突（又要固定机位又要推近）时取用户意图更强的那个。
4. 光线必须有**来源**，对比必须有**位置**（亮部在哪暗部在哪），色调最好有**光源依据**（霓虹/油灯/月光）。
