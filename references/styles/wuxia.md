# 武侠 Wuxia

> 东方古典武侠美学：写意留白、水墨意境、飘逸轻盈的动作、自然诗意的光色。胡金铨/张艺谋/王家卫路线，重意境而非写实。

## ① 一句话基调
**写意、留白、飘逸、诗意。** 不是追求打斗的真实冲击，是追求"侠"的意境——竹林、水墨、长衫在风里，动作如舞如诗。

## ② 光线配置
| 项 | 写法 |
|---|---|
| **质感** | 柔和自然光（晨雾/斜阳/月光），避免硬光 |
| **标志** | 林间漏光（dappled light through bamboo）、晨雾中的体积光、逆光勾轮廓 |
| **方向** | 逆光/侧逆光勾出人物轮廓和飘动衣袂 |
| **氛围** | 雾气弥漫（晨雾/山岚），光有介质可见 |

**典型光源词**：dappled sunlight through bamboo、misty morning backlight、moonlit courtyard、golden hour haze。

## ③ 色彩调性
| 路线 | 色彩 |
|---|---|
| **水墨写意** | 低饱和、青灰/墨色、大面积留白（雾/白墙/天空） |
| **浓烈张艺谋式** | 单色大色块（全红/全绿/全黄竹林），极致风格化 |
| **自然诗意** | 青绿山水、暖金斜阳 |
| **禁忌色** | 脏乱杂色、现代冷白光、高科技色 |

**调色法**：desaturated ink-wash（水墨）、或 bold monochrome color blocks（张艺谋式单色）、青绿调、留白高调。

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| **构图** | 大面积负空间/留白（意境核心）、低地平线、框中框（月洞门/窗棂）、对称（庭院/建筑） |
| **运镜** | 缓慢优雅的移动、弧形环绕（打斗）、升降（展现轻功高度）、慢动作飘逸 |
| **景别** | 大远景交代山水意境 + 中近景看人物神韵，善用极端对比 |
| **焦段** | 长焦压缩（竹林层叠）或广角展现山水辽阔 |

**典型构图元素**：竹林/山水/庭院、飘动的长衫衣袂、月洞门框、水面倒影、留白的天空/雾。

## ⑤ 质感与禁忌
**必备质感**：
- 雾气/山岚（意境介质 + 光束载体）
- 飘动的布料（衣袂、绸缎，慢动作）
- 水墨晕染感（低饱和、柔边）
- 慢动作飘逸（轻功、落叶、衣袂）

**禁忌清单**：
- ❌ 硬光高反差（那是黑色电影，不是武侠）
- ❌ 现代感、冷白光、高科技元素
- ❌ 写实血腥的暴力（武侠重写意，点到为止）
- ❌ 杂乱构图（武侠讲究留白与呼吸感）

## 提示词模板（拿来就用）

```
[主体] in a misty bamboo forest, flowing robes billowing in the wind, 
dappled golden backlight through bamboo, morning haze with volumetric light, 
vast negative space, low horizon, 
desaturated ink-wash color palette, 
slow-motion drifting leaves, 
telephoto compression layering the bamboo, poetic and ethereal
```

张艺谋式变体：把 `desaturated ink-wash` 换成 `bold monochrome [red/green/yellow] color block, hyper-saturated silk fabric`。

关键词组合拳：wuxia + flowing robes + dappled backlight + bamboo + morning haze + negative space + ink-wash + slow motion + telephoto。
