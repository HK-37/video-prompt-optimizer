# 赛博朋克 / 科技黑色 Cyberpunk / Tech-Noir

> 高科技低生活：霓虹雨夜、巨型全息广告、湿漉街道反光、冷暖对冲的未来贫民窟。AI 视频最高频风格之一。

## ① 一句话基调
**霓虹 + 雨夜 + 反光 + 冷暖对冲。** 繁华科技与底层破败并置，光是彩色的、地是湿的、天总在下雨。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 彩色霓虹实用光（neon practical）为主光，低调布光大面积暗部 |
| 标志 | 全息广告/招牌自发光映在脸和湿地面上，青红双色对冲 |
| 方向 | 侧逆光勾轮廓 + 底部地面反光补光 |
| 禁忌 | 均匀白天光、暖阳、高调明亮 |

典型光源词：neon signs、holographic billboard glow、LED strips、rain-wet pavement reflection、backlit mist。

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 青/品红/电蓝霓虹 vs 暗部深黑，高饱和对冲 |
| 暗部 | 压到近黑（crushed blacks），霓虹才跳得出来 |
| 禁忌色 | 暖黄温馨、自然柔和、低饱和灰（那是别的风格） |

调色法：teal-magenta neon、high saturation、crushed blacks、冷暖强对比。

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 构图 | 层次纵深（前景霓虹/招牌框住主体）、框中框、一点透视（街道/走廊） |
| 运镜 | 缓慢推进、跟拍、低空 FPV 穿街 |
| 景别 | 大远景立城市天际线 + 中近景看人物霓虹映脸 |
| 焦段 | 广角纳入巨构 / 长焦压缩街道人潮 |

典型元素：摩天楼、全息投影、飞行器、机械义体、雨伞人流、蒸汽排气、巨型广告屏。

## ⑤ 质感与禁忌
必备：雨/湿地反光、霓虹散景 bokeh、烟雾/蒸汽、镜头光晕、轻颗粒。
禁忌：❌ 晴天暖光 ❌ 田园自然 ❌ 干净极简（赛博要"脏、挤、湿、亮"）。
