# 梦核 Dreamcore

> 似曾相识的梦境美学：空旷的熟悉场景、过曝柔光、不安的宁静。网络超现实美学正热，AI 视频高产。

## ① 一句话基调
**熟悉又不对劲的空旷梦境。** 场景是你见过的（泳池、走廊、游乐场），但空无一人、光不对、时间停滞——像梦里到过的地方，宁静中透着说不清的不安。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 过曝柔光、朦胧弥散、光源不明确（整体发亮却没有明确太阳） |
| 标志 | 泳池反光、荧光灯惨白、黄昏将尽的暧昧光、过曝到发白 |
| 禁忌 | 硬朗明确的戏剧光、清晰的光源方向 |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 褪色柔和、粉蓝/暖黄/薄荷绿的淡调，或过曝泛白 |
| 质感 | 老照片褪色感、轻微噪点、梦境般不真切 |
| 禁忌色 | 高对比鲜艳、冷峻商业调 |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 构图 | 空旷对称、大量留白、熟悉场景但空无一人、一点透视的无尽延伸 |
| 运镜 | 缓慢飘移、梦游式推进、无目的游荡 |
| 景别 | 全景交代空旷、走廊/泳池的纵深 |

典型元素：空泳池、无尽走廊、深夜游乐场、空荡商场、老旧室内、没有人的熟悉场所、"liminal space 阈限空间"。

## ⑤ 质感与禁忌
必备：熟悉空旷场景、过曝柔光、褪色调、空无一人、宁静的不安感、阈限空间。
禁忌：❌ 人多热闹 ❌ 硬朗清晰光 ❌ 高饱和鲜艳 ❌ 明确叙事（梦核靠氛围不靠情节）。

## 提示词模板
```
[熟悉场景：empty swimming pool / endless corridor / deserted mall] dreamcore aesthetic, 
liminal space, overexposed hazy soft light, no visible light source, 
faded pastel palette washed out, 
empty and silent, symmetrical vast negative space, 
one-point perspective endless depth, 
slow drifting camera, nostalgic uneasy dreamlike stillness
```
关键词组合拳：dreamcore + liminal space + overexposed hazy + faded pastel + empty silent + symmetrical + uneasy stillness。
> 和 weirdcore 区别：dreamcore 偏"宁静怀旧的不安"，weirdcore 更"诡异扭曲+粗糙故障"。
