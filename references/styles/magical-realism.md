# 魔幻现实 Magical Realism

> 日常场景里藏着不被惊讶的超现实。写实的世界 + 一两处违反物理却被当作理所当然的奇迹。文艺向短片高频。

## ① 一句话基调
**写实打底 + 一处静默的奇迹。** 场景完全真实日常，但有一个超现实元素自然地存在，没人觉得奇怪——克制是关键，不是奇观堆砌。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 柔和自然光为主、黄金时刻、窗光，营造"真实但有点梦" |
| 标志 | 奇迹元素可带一点非自然的光（自发光/异常投影），其余写实 |
| 禁忌 | 全程奇幻打光（会变成纯奇幻，失去"现实"地基） |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 偏写实但略提饱和/略暖，像记忆被美化过 |
| 质感 | 褪色胶片感、柔和、诗意，不要锐利数码感 |
| 禁忌色 | 高对比商业调、硬朗冷峻（气质不符） |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 运镜 | 缓慢、克制、凝视感；长镜头让奇迹"自然发生" |
| 构图 | 对称/留白/框中框，给超现实元素一个安静的位置 |
| 景别 | 中景到全景，让奇迹与日常同框（对比才成立） |
| 焦段 | 中焦自然、浅景深柔化 |

典型元素：漂浮的日常物、室内下雨/落花、异常的影子、与动物/逝者自然对话、时间停滞的瞬间——**但场景其余部分完全写实**。

## ⑤ 质感与禁忌
必备：写实场景地基、单一克制的超现实元素、柔和诗意光色、缓慢凝视的节奏。
禁忌：❌ 奇观堆砌（多个奇迹=奇幻片不是魔幻现实）❌ 夸张特效感 ❌ 角色对奇迹大惊小怪（魔幻现实的奇迹是"被接受的"）。

## 提示词模板
```
[写实日常场景] with one quiet surreal element [如：petals falling indoors / a figure floating gently], 
photorealistic setting, soft golden natural light, 
the surreal treated as ordinary, no reaction of surprise, 
symmetrical composition with negative space, 
slow contemplative pacing, faded filmic color, poetic and understated
```
关键词组合拳：magical realism + photorealistic setting + one quiet surreal element + treated as ordinary + soft natural light + poetic understated。
