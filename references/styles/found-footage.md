# 伪记录 Found Footage

> "被发现的录像"美学：设备内第一视角、画质故障、业余拍摄感。恐怖片超高频套路（《女巫布莱尔》《鬼影实录》系）。

## ① 一句话基调
**设备视角 + 故障感 + 业余手持。** 核心是"这是某个设备真实拍到的素材"——所以画质差、会抖、有噪点、有时间码。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 全靠现场光/设备自带光（手电、夜视、手机闪光） |
| 标志 | 夜视绿、手电光锥在黑暗中扫、过曝/欠曝的自动调节 |
| 禁忌 | 任何"打过光"的痕迹——没有布光，只有现场有啥用啥 |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 还原但带设备偏色（DV 偏蓝、夜视绿、手机惨白） |
| 质感 | 数码噪点、压缩失真、画质粗糙 |
| 禁忌色 | 精致电影调色（一调色就"假"了） |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 运镜 | 剧烈手持晃动、奔跑中拍摄、突然甩动失焦 |
| 构图 | 极度不稳、构图随意、主体常跑出画、仰拍俯拍混乱 |
| 标志元素 | 屏幕 UI（录制红点、电量、时间码）、信号干扰雪花、画面卡顿 |
| 焦段 | 自动变焦乱拉、自动对焦来回拉风箱 |

典型元素：手持 DV/手机/行车记录仪/监控视角、夜视模式、录制时间码、信号故障、黑暗中手电。

## ⑤ 质感与禁忌
必备：手持剧烈晃动、数码噪点、设备 UI 叠加、故障/卡顿、现场光。
禁忌：❌ 稳定运镜 ❌ 专业布光 ❌ 精致调色 ❌ 完美构图（全反着来）。

## 提示词模板
```
[主体/事件] found footage style, shaky handheld camcorder POV, 
night vision green [or] harsh phone flashlight in darkness, 
digital noise and compression artifacts, 
on-screen recording UI (red dot, timecode, battery), 
unstable framing with subject drifting out of frame, 
autofocus hunting, signal glitches, raw amateur realism
```
关键词组合拳：found footage + shaky handheld + night vision / flashlight + digital noise + recording UI + timecode + glitches。
