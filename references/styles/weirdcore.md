# 怪核 Weirdcore

> 刻意粗糙的诡异超现实：低画质、故障、扭曲、不安的标注文字。比梦核更"脏、怪、不适"。网络亚文化高产。

## ① 一句话基调
**粗糙 + 诡异 + 故障 + 不适。** 和梦核的"宁静怀旧"不同，怪核是主动制造不安——低画质老照片、扭曲变形、乱入的箭头/文字标注、说不出哪里错了的恐怖谷。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 劣质闪光灯直打、过曝/欠曝失衡、廉价数码感 |
| 标志 | 老式相机闪光、荧光灯惨白、夜晚闪光打出的生硬阴影 |
| 禁忌 | 讲究的电影布光（怪核要"业余、劣质、随意"） |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 老照片褪色偏黄/偏绿、低画质偏色、不自然的饱和 |
| 质感 | 重噪点、JPEG 压缩失真、扫描失真、画质劣化 |
| 禁忌色 | 干净高清、精致调色 |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 构图 | 怪异视角、扭曲变形、主体畸形、构图"不对劲" |
| 叠加元素 | **乱入的红色箭头/圈注/手写文字/表情符号**（怪核标志）、马赛克遮挡 |
| 质感 | 低分辨率、故障 glitch、像素化崩坏、恐怖谷 |

典型元素：扭曲的脸/身体、乱标的箭头文字、低画质老照片、荧光灯空间、诡异玩偶、变形建筑。

## ⑤ 质感与禁忌
必备：低画质重噪点、劣质闪光、扭曲变形、乱入标注文字/箭头、故障感、恐怖谷不适。
禁忌：❌ 高清精致 ❌ 电影布光 ❌ 宁静唯美（那偏梦核）❌ 和谐舒适。

## 提示词模板
```
[主体/场景] weirdcore aesthetic, low-quality degraded photo, 
harsh direct flash, overexposed with heavy noise, 
distorted warped subject, uncanny valley, 
random red arrows and handwritten text annotations overlaid, 
JPEG compression artifacts, glitch, 
disorienting uneasy wrongness
```
关键词组合拳：weirdcore + low-quality degraded + harsh flash + distorted warped + red arrows/text overlay + JPEG artifacts + uncanny。
