# 艺术电影 Arthouse

> 作者电影美学：克制、留白、长镜头、构图精确、情绪大于情节。塔可夫斯基/是枝裕和/阿克曼系。文艺向通用底。

## ① 一句话基调
**克制 + 精确 + 凝视。** 不炫技、不煽情，靠精确的构图、缓慢的时间、大量留白让观众"自己感受"。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 自然光优先、柔和、动机光；窗光/天光，真实又讲究 |
| 标志 | 单一光源的精确控制、明暗过渡细腻、不戏剧化但很准 |
| 禁忌 | 浮夸打光、商业感高光、无动机的炫光 |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 低饱和、沉静、自然；常用统一的冷调或暖调基底 |
| 质感 | 胶片感、细腻、克制，绝不艳俗 |
| 禁忌色 | 高饱和商业调、青橙烂大街调 |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 运镜 | **长镜头**（oner）、固定长凝视、极缓移动——时间本身是表达 |
| 构图 | 精确对称/几何、大面积留白、框中框、人物居边缘 |
| 景别 | 偏爱全景/中景的"观察距离"，少用特写煽情 |
| 焦段 | 中焦自然、深景深（让观众自由看画面各处） |

典型手法：静止长镜看人物发呆、空镜承载情绪、门窗框构图、对称空间、留白等待。

## ⑤ 质感与禁忌
必备：长镜头、精确构图、留白、低饱和沉静、自然动机光、慢节奏。
禁忌：❌ 快切炫技 ❌ 煽情配乐式画面 ❌ 高饱和商业调 ❌ 密集信息（艺术片靠"少"）。

## 提示词模板
```
[主体/场景] arthouse cinema style, long static take, 
precise symmetrical composition with negative space, 
natural motivated window light, soft tonal transitions, 
desaturated restrained palette, filmic texture, 
deep focus, contemplative slow pacing, Tarkovsky / Kore-eda sensibility
```
关键词组合拳：arthouse + long take + precise symmetry + negative space + natural motivated light + desaturated restrained + contemplative。
> 与"魔幻现实"区别：arthouse 不需要超现实元素，纯靠写实的克制；可叠加（文艺的魔幻现实）。
