# 纪录片 Documentary

> 真实感美学：自然光、手持、不完美构图。核心是"看起来没被设计过"。伪纪录、真实感叙事的万用底。

## ① 一句话基调
**自然、手持、不摆拍。** 一切为"真实"服务——光是现场有的，镜头会晃，构图允许不完美。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 现场可用光（available light）、自然光优先、不打戏剧光 |
| 标志 | 窗光、天光、现场灯——光比真实，不刻意造型 |
| 禁忌 | 戏剧性硬光、三点布光的"完美感"、人工轮廓光 |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 自然还原、低饱和偏写实、不做风格化调色 |
| 质感 | 可轻微数码感或新闻纪实感，避免电影化重调色 |
| 禁忌色 | 青橙调、强风格化偏色（那就"假"了） |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 运镜 | 手持轻微晃动（核心标志）、跟随、临场抓拍感 |
| 构图 | 允许不完美——偶尔失焦再追焦、构图偏、headroom 不标准 |
| 景别 | 采访中近景 + 环境交代空镜 + 抓拍细节 |
| 焦段 | 变焦可见（zoom in 抓细节）、浅焦跟焦 |

典型元素：采访机位、手持跟拍、现场环境音感、旁观视角、真实场景不布景。

## ⑤ 质感与禁忌
必备：手持微晃、自然光、跟焦/追焦、真实场景、临场感。
禁忌：❌ 完美稳定的轨道镜 ❌ 戏剧性布光 ❌ 重风格化调色 ❌ 过度设计的构图。

## 提示词模板
```
[主体/事件] documentary style, handheld camera with subtle shake, 
natural available light, realistic color grading, 
imperfect framing, candid observational angle, 
shallow focus follow-focus, authentic unstaged location, 
cinéma vérité realism
```
关键词组合拳：documentary + handheld + available light + candid + imperfect framing + unstaged。
> 伪纪录(found footage)另有独立包，区别：found footage 更强调"设备内视角/故障感"，documentary 是"专业纪录片质感"。
