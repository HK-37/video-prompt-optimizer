# 摄影 Photography（写真 / 相机质感）

> "像一张精心拍的照片"的美学。强调真实相机的光学质感、专业布光、决定性瞬间。人像/静物/时尚/街拍写真高频。

> ⚠️ 这是"相机媒介质感"风格，不是某个电影流派。用户说"要摄影感/写真感/大片感"时用。分支按题材走。

## ① 一句话基调
**真实光学 + 专业布光 + 决定性瞬间。** 核心是让画面像"摄影师用好镜头+好布光拍的照片"，而非随手截图。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 专业布光（可点名三点/伦勃朗/蝴蝶光）或讲究的自然光 |
| 标志 | 柔光箱柔光、窗光人像、黄金时刻外拍、影棚纯色背景 |
| 禁忌 | 随意平光、无控制的现场光（那是快照不是摄影） |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 分支 | 时尚大片（高级灰/高对比）、胶片写真（柔和颗粒）、商业静物（干净高调） |
| 质感 | 可点名胶片型号感（Portra 暖柔、Kodachrome 高饱和）或数码清透 |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 焦段 | **这是重点**——85mm/135mm 人像浅景深散景、35mm 街拍、微距静物 |
| 构图 | 严谨三分/中心、留白、引导线，像构过图的照片 |
| 景深 | 浅景深奶油散景（人像标志）或深景深风光 |
| 运镜 | 视频化时极缓或近乎静止（照片感=少动） |

分支题材：人像写真、时尚大片、街头摄影、静物商业、风光摄影、黑白纪实。

## ⑤ 质感与禁忌
必备：明确焦段+景深、专业布光或讲究自然光、严谨构图、相机光学质感（散景/眩光/颗粒）。
禁忌：❌ 随手快照感 ❌ 无控制平光 ❌ 构图随意。

## 提示词模板
```
[主体] professional photography, 85mm portrait lens, 
creamy shallow depth-of-field bokeh, soft window light [or softbox], 
careful rule-of-thirds composition, 
Kodak Portra film tones [or clean digital], 
sharp optical detail, decisive moment, editorial quality
```
关键词组合拳：photography + 明确焦段(85mm/35mm/macro) + 景深 + 专业布光 + 严谨构图 + 胶片/数码质感。
> 和"纪录片"区别：documentary 要"不完美的真实"，photography 要"精心控制的完美"。两者相反。
