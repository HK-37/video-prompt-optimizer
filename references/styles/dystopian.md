# 反乌托邦 Dystopian

> 压抑的未来/极权社会美学：冷灰工业、监控感、个体渺小。《1984》《银翼杀手》灰暗面、《妙探》系。科幻短片常用。

## ① 一句话基调
**冷灰 + 压迫 + 秩序森严。** 和赛博朋克的"霓虹繁华"不同，反乌托邦是"去色、肃杀、人被体制碾压"的冷感。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 冷硬光、顶光压迫、大面积均匀冷光（像机构照明） |
| 标志 | 监控探照、冷白荧光、逆光剪影下的人群 |
| 禁忌 | 暖色温馨、柔美自然光 |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 冷灰/青灰/去饱和，接近单色 |
| 暗部 | 沉闷不透亮，整体压抑 |
| 点缀 | 偶尔一抹刺目的体制色（标语红/警示黄） |
| 禁忌色 | 暖黄、高饱和明快、糖果色 |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 构图 | 对称/一点透视（极权秩序感）、大面积几何、个体居渺小位 |
| 机位 | 高角度俯拍（压制）、大远景（吞没个体） |
| 运镜 | 缓慢、冷静、机械感；固定或匀速平移 |
| 焦段 | 广角纳入巨构 / 长焦压缩人群成无差别队列 |

典型元素：巨型建筑/标语、监控摄像、统一制服人群、冷峻走廊、检查站、灰色天空。

## ⑤ 质感与禁忌
必备：冷灰去饱和、对称秩序构图、个体渺小、肃杀空旷、轻度颗粒。
禁忌：❌ 温暖 ❌ 霓虹繁华（那是赛博）❌ 自然田园 ❌ 热闹人情味。

## 提示词模板
```
[主体] in a dystopian [场景：plaza/corridor/checkpoint], 
cold grey desaturated palette, oppressive top lighting, 
monumental symmetrical architecture, one-point perspective, 
the individual dwarfed by the structure, high-angle shot, 
uniform crowds, a single jarring accent color [propaganda red], 
slow cold camera, wide-angle, light grain, bleak and austere
```
关键词组合拳：dystopian + cold grey desaturated + oppressive top light + monumental symmetry + dwarfed individual + high-angle + austere。
