# 德国表现主义 German Expressionism

> 1920s 默片美学：极端扭曲布景、尖锐阴影、强烈明暗对比。《卡里加里博士》《大都会》系。恐怖/悬疑的视觉源头，被后世大量引用。

## ① 一句话基调
**扭曲 + 尖锐阴影 + 极端明暗。** 用倾斜变形的布景和手绘般的锐利阴影，把人物内心的不安外化成"扭曲的世界本身"。

## ② 光线配置
| 项 | 写法 |
|---|---|
| 质感 | 极端高反差（黑白强对比）、硬光、大片死黑 + 刀刻般亮部 |
| 标志 | 尖锐的长投影（常与实体不符、画上去般夸张）、底光/侧光造怪影 |
| 禁忌 | 柔光、均匀光、低反差（表现主义就是靠极端光影） |

## ③ 色彩调性
| 项 | 用法 |
|---|---|
| 主色 | 黑白高反差（经典）；彩色化则用单一病态色主导 |
| 质感 | 刀刻感、版画感、强硬边缘阴影 |
| 禁忌色 | 柔和自然、低对比、写实还原 |

## ④ 镜头与构图
| 项 | 配置 |
|---|---|
| 标志手法 | **扭曲倾斜的布景**（墙歪、门斜、楼梯畸形）、荷兰角、尖锐几何 |
| 构图 | 不稳定倾斜、尖角指向、夸张透视、阴影作为构图主体 |
| 机位 | 荷兰角、仰视怪影、剪影逼近 |
| 运镜 | 缓慢不安、固定造型化画面 |

典型元素：扭曲的建筑/楼梯、墙上夸张的长影、苍白化妆的脸、尖锐几何、逼近的剪影、畸形空间。

## ⑤ 质感与禁忌
必备：极端黑白高反差、尖锐长投影、扭曲倾斜布景、荷兰角、版画刀刻感。
禁忌：❌ 柔光写实 ❌ 稳定正常的空间 ❌ 低对比自然色（完全反其道）。

## 提示词模板
```
[主体/场景] German Expressionist style, extreme high-contrast black and white, 
sharp exaggerated painted-on shadows, distorted tilted architecture, 
warped staircases and crooked walls, dutch angle, 
hard low-angle light casting monstrous shadows, 
angular geometry, woodcut-like harsh edges, 
Caligari aesthetic, unstable and menacing
```
关键词组合拳：German Expressionism + extreme high-contrast B&W + sharp exaggerated shadows + distorted tilted architecture + dutch angle + Caligari。
