# mood-to-shot — 氛围 → 镜头方案映射表

> **这页解决什么**：用户常常只会说"我想要 XX 氛围/感觉"，不懂镜头、也没有具体想法。这张表把**氛围诉求**直接翻译成**一整套镜头配置**——照着就能拼出提示词。
>
> **它在 skill 里的位置**：是 12 维镜头清单 + word-bank 的**正向总入口**。
> - 用户给了具体镜头想法 → 直接走 checklist 逐维补。
> - 用户只给氛围词（"要压抑""要孤独"）→ **先查本表拿整套配置**，再用 word-bank 填具体内容、checklist 微调。
>
> **与 word-bank 两张表的分工**（不重复）：
> - C 档情绪表：情绪词 → 一两句画面指令（**局部、单点**）。
> - 气质词表：角色气质 → 身体语言（**只管人物姿态**）。
> - **本表：氛围 → 整镜 7 项配置（景别/运镜/光/色/焦段/构图/节奏）+ 一句话画面（全局、成套）**。三者配合用：本表定全局镜头，气质表定人怎么站，C 档补情绪细节。
>
> 建立：2026-10-27。

---

## 用法（三步）

1. 听用户的氛围词，在下表找最近的一行（没有完全对应的，找气质/情绪最接近的，或组合两行）。
2. 把那一行的 7 项配置抄成镜头骨架。
3. 用 word-bank 填入用户要的**具体内容**（主体/动作/器物），再按需微调。**注意守总则铁律：不往画面里塞用户没提的新实体。**

> ⚠️ 表给的是"默认最优解"，不是铁律。用户若另有想法以用户为准；一条提示词仍只用一种运镜。

## 组合与进阶

- **复合氛围**：用户说"孤独又宿命" → 取孤独系的大远景负空间 + 宿命系的俯拍去饱和，融合即可。
- **氛围会被两轴合力改写**（见 content-map 总则）：本表给的是"镜头侧的语气"，还要配 word-bank 的"内容侧证据"（荒凉配破败器物、浮尘）才完整。
- **强风格片**：先定氛围（本表）再套风格包（styles/）。例：武侠片的"孤独"= 本表孤独系 + wuxia.md 的水墨留白，叠加不冲突。
- **节奏列对接**：节奏项（慢/变速/快）落到 checklist 第10维"时间与运动"和运镜速度，是"镜头节奏"的直接抓手。

## 六、场景需求词 → 节奏意图（潜台词推断入口）

上表接的是**用户点名的氛围词**（"要压抑""想孤独"）。但用户常说的是**场景需求 / 规模 / 刺激类词**（"场面大""刺激""燃""爽""紧张感"），这些词字面是尺度或感受，潜台词通常是**情节/镜头节奏的紧张、刺激**。它们不会命中上表任何一行，需要你先**推断其节奏意图**，再落到对应行的「节奏」列。

| 用户说"…" | 默认候选节奏意图 | 落点（本表行 + 维度） | 校准 / 歧义提醒 |
|---|---|---|---|
| **场面大 / 宏大 / 震撼** | 史诗壮阔 **或** 紧张刺激（二选一，看类型） | 史诗/壮阔 行（舒展大气）｜紧张/悬疑 行（静中有微动） | **一词多义**：动作追逐/枪战→紧张刺激；战争史诗/自然奇观→壮阔舒缓。类型不明**向用户确认**，勿硬编码 |
| **刺激 / 燃 / 爽 / 燃爆了** | 热血 / 爆发、速度 / 追逐 | 热血/爆发 行（变速蓄—爆）｜速度/追逐 行（快冲） | 落到第10维「时间运动」做变速/快切 |
| **紧张感 / 惊险 / 揪心** | 紧张 / 悬疑 | 紧张/悬疑 行（静中有细微动、光比拉大） | 慢中有紧，不是越快越好 |
| **混乱 / 失控 / 炸裂** | 混乱 / 失控 | 混乱/失控 行（急、碎、手持晃） | 节奏碎≠乱写，仍守单运镜 |

**用法**：扫到这类词 → 按上表定节奏意图 → 抄对应行的 7 项配置（或只取其「节奏」列 + 第4步时间运动维度）→ 与用户要的具体内容（主体/动作）合成。尺度层（大全景/广角）与节奏层（快切/变速）可共存——"大"管规模、"紧"管张力。

**与「只增强不新增」不冲突**：这是细化用户已表达的意图，不是新增实体/风格。

## 七、动作意图词 → 强度 / 互动结构（主动词推断入口）

第六节接的是**形容词**（场面大 / 刺激 → 节奏）。但一句需求里最该被推断的往往是**主动词**：用户说"追逐""互相乱射"，字面只是个动词，背后藏着**方向性、频率、位形**三件事。不推断就会把动词照抄成一个最弱的静态 pose——**要素全对、戏全无**。

| 用户说"…" | 三属性（方向 / 频率 / 位形） | 必须写进画面的证据 | ❌ 常见降级写法 |
|---|---|---|---|
| **追逐 / 你追我赶 / 飙车** | 双向 / 连续 / 前后位差 + 换位 | 前后车距几米、后车车灯打在前车尾部、并线逼近、超车瞬间前车被压到画面后侧、换位后重新拉开 | "两车并排疾驰""并肩飞驰""贴地疾驰" |
| **互相射击 / 对射 / 乱射** | 双向 / 连续多次·高频 / 弹道交错 | 双方交替击发、多组枪口火光、弹道在两车之间交错、车身多处迸出火星、压车闪避 / 侧身回击的反应 | "各举一支手枪平举、扣动扳机"（一次、静态、朝向不明） |
| **缠斗 / 搏杀** | 双向 / 连续 / 位形反复互换 | 三帧法起势→冲击→反应，每帧重心与占位互换 | "对峙""摆开架势" |
| **围攻 / 群战** | 多向 / 连续 / 包围位形 | 前景背影 + 画面深处多人合围，留一个缺口给视线 | "几个人打一个人" |
| **逃亡 / 闪避** | 单向 / 连续 / 被追者的反应 | 回头、急转、擦过障碍、身后逼近的车灯 | "拼命跑" |

**用法**：扫主动词 → 标三属性 → 按上表把"证据"落成可见画面节拍 → 与第 1.5 步的节奏层、尺度层叠加（三者可共存：**强度管"戏"、节奏管"紧"、尺度管"大"**）。

**不许降级**：审核只删血腥 / 伤口，不删频率与双向性；稳定性靠拆镜 / 参考图，不靠把动词写弱。附加偏好（"另外还挺喜欢…"）不得挤掉主诉求动词的篇幅。

**一条自检**：写完后回看每个主动词——如果把它替换成表里 ❌ 那列的说法，用户会不会觉得"这不是我要的"？会，就说明降级了。

**与「只增强不新增」不冲突**：这是把用户已给的动词展开到它本来的强度，不是新增实体/风格。

## 覆盖缺口

本表覆盖 5 系 18 种高频氛围。用户的氛围词找不到对应、或给出的配置实测不对时 → 本地记下来，由使用者判断是否补进本表新增行。
