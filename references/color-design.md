# 色彩设计（color design）

> 用途：当需求涉及"情绪/氛围/风格的颜色呈现"，或做**多镜短片**要统一色彩时查这里。
> 定位：checklist 第7维（色调）管"单镜用什么色"，本文件管**更上一层**——为什么用这个色、整部片色彩怎么随情绪走、怎么配得克制有序。
> 核心原则：**颜色不是装饰，是情绪的载体**。观众先感知色温情绪、才理性看内容。写提示词时"有理由地给色"，别堆。

---

## 一、color script：全片色彩弧（多镜短片必看）

单镜定一个色调不难，难的是**整部片的颜色随情绪走出一条弧线**。这就是 Pixal 发明的 color script——把每一场的主色排成一条序列，一眼看出情绪起伏。

**怎么用（AI 多镜短片版）**：开拍前先定全片的"色彩弧"，每一段落一个主基调，让颜色替你讲情绪推进：

| 叙事阶段 | 色彩走向 | 例 |
|---|---|---|
| 开场/日常 | 中性或暖，饱和适中 | 暖黄、自然光 |
| 冲突/压抑 | 冷、褪色、低饱和 | 冷蓝灰、去饱和 |
| 最低点/绝望 | 极冷或单色、近黑 | 墨蓝、单色、crushed black |
| 转机/爆发 | 饱和猛拉、暖色回归或强对冲 | 赤红、金、强橙青 |
| 收束 | 回到开场色但微变（暗示改变） | 暖黄但更沉 |

**落地**：多镜时，把"这一段是什么情绪→对应什么色"写进每镜提示词的色调项，保证颜色跨镜有逻辑、不是每镜随机。呼应 shot-continuity 的"调色一致是情绪锚"。

**案例**：双塔对峙片——紫方(神性/静)冷紫蓝贯穿、红方(野性/动)赤红贯穿，两条色线本身就是"对立"的色彩表达。这就是 color script 思维。

## 二、色彩心理对照表（哪个色 = 哪种情绪）

观众对颜色的情绪反应是**先于理性**的。下面是通用对照（文化默认值，非绝对）：

| 色 | 情绪/联想 | 适用场景 |
|---|---|---|
| 红 | 危险、激情、暴力、警示、生命力 | 冲突、欲望、高能、血性 |
| 橙 | 温暖、活力、怀旧、廉价欢乐 | 黄金时刻、温馨、复古 |
| 黄 | 希望、快乐、病态、疯狂（高饱和时） | 童年、不安（脏黄）、警觉 |
| 绿 | 自然、治愈、诡异、病毒、金钱 | 森林宁静 / 中毒不祥（Matrix 绿=虚拟） |
| 青/蓝绿 | 冷静、科技、疏离、现代 | 赛博、医疗、冷峻；橙青的"青"侧 |
| 蓝 | 忧郁、神秘、冷静、专业、孤独 | 夜、水下、悲伤、理性 |
| 紫 | 神秘、高贵、神性、迷幻、不安 | 神性、魔法、梦境 |
| 黑 | 力量、死亡、未知、高级、虚无 | 恐怖、权力、极简、crushed black |
| 白 | 纯洁、空无、冷清、神圣、医院感 | 留白、神性、荒凉、临床 |
| 金 | 奢华、神圣、辉煌、怀旧 | 宫廷、神性勾边、黄金时刻 |

**用法**：用户给情绪词→查这表定主色方向，再回 checklist 第7维选具体调色法。注意**同色高低饱和差很多**（高饱和黄=疯狂，低饱和黄=怀旧），饱和度要一起定。

## 三、色彩和谐方案（怎么配才"克制有序"）

"克制有序"是成熟色彩设计的通用目标——**用成熟配色方案，不是乱堆颜色**。

| 方案 | 怎么配 | 效果 | 例 |
|---|---|---|---|
| **互补** complementary | 色环对面两色（橙↔青、红↔绿、黄↔紫） | 强对冲、张力、把主体从背景抠出 | 橙青大片（最流行） |
| **类比** analogous | 色环相邻 2-3 色（蓝+青+绿） | 和谐、统一、宁静 | 单一基调的氛围片 |
| **三角** triadic | 色环均匀三点（红+黄+蓝） | 活泼、均衡、丰富 | 动画、童趣、热闹 |
| **分裂互补** split-comp | 一主色 + 对面色的相邻两色 | 有对比但比纯互补柔 | 需要对比又怕太冲时 |
| **单色** monochrome | 一个色相的明度/饱和度变化 | 极致统一、风格化、情绪纯粹 | 单色调艺术片、沙尘回忆 |

**限制调色板铁律**：一帧主色压到 **2-3 种**（主色+辅色+点缀），画面才"像设计过"。颜色越多越乱，这是"克制有序"的技术落点。

## 四、橙青（teal-orange）：为什么有效、何时避开

**为什么全球烂大街**：人的肤色天然落在橙/黄区间，把背景推向青 → 冷暖互补**自动把人从背景里剥离**，不用补光、不用浅景深就有"电影感"。这是它流行的真实技术原因，不是玄学。

**何时避开**：
- 滥用 = 千片一面的"能量饮料色"，廉价。
- **写实/纪实题材反而该收着**——自然主义（Deakins《Sicario》）是刻意选择不上橙青，让画面"可信"。
- 想要个人印记时，主动选别的方案（单色/类比/一个非常规主色）比跟风橙青更高级。

**判断**：要"快速电影感、人物要跳出来"→橙青可用；要"真实/高级/有个人味"→避开，另选。

## 五、调色工序意识（AI 提示词版）

后期调色的专业顺序是**①技术校正 ②镜头匹配 ③创意调色**——先校正白平衡曝光，再统一镜头，最后才谈风格化。

**映射到写提示词**：先把"画面基础"说准（光源、明暗、基调色温），**再叠风格化调色**。别一上来就堆"赛博朋克霓虹强对冲 bleach bypass 橙青"一串风格词——基础没立住，风格叠上去就是乱。顺序：先定"这场是什么光什么基调" → 再加"往哪个风格推"。

## 六、名片色彩案例（可直接借的成品色板）

| 片 | 色彩手法 | 情绪 |
|---|---|---|
| Matrix | 绿=虚拟世界 / 蓝=真实世界，双色分世界 | 用色区分两个层面 |
| Blade Runner 2049 | 大色块单色场景切换（橙沙尘/青夜/红密室） | 每场一个强单色，极致风格化 |
| Amélie | 金+绿，饱和暖 | 童话、温暖、怀旧 |
| Mad Max: Fury Road | 极端橙青（白天橙沙、夜晚青蓝） | 把橙青推到漫画级当风格 |
| Moonlight | 每一幕一个色温对应主角心理阶段 | 色彩=人物内心弧 |
| Sicario（Deakins） | 自然主义、几乎不调色 | 真实、冷峻、克制（反橙青范例） |
| 黑色电影/工业 | bleach bypass：低饱和高对比、奶灰接近黑白 | 硬、冷、绝望、工业感 |

**用法**：用户说"要 XX 片那种颜色"→从这里找手法，翻译成具体调色词填进提示词。

## 速用路径

1. 多镜短片 → 先定全片 color script 色彩弧（第一节）。
2. 单个画面要什么情绪 → 查色彩心理表定主色（第二节）→ 选和谐方案（第三节）→ 限制 2-3 色。
3. 要不要上橙青 → 第四节判断。
4. 写提示词 → 先基础基调、后风格化（第五节）。
5. 要对标某片 → 第六节找手法。
