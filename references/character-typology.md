# 角色造型判据库（character typology）

> **定位**：查表判断（查错用）。与 `templates.md` 的「填空骨架（写稿用）」分工，互不混装——一处知识只有一个家。
> **路由**：`preflight.md` 第 0 项判定题材 / 原型是否命中本库 → 命中则把「必须写进画面的证据」逐维落进提示词；未命中转 `visual-probe.md` 探路，定稿后回填本库一行。
> **结构范式**：取自 `mood-to-shot.md` 第七节（词 / 题材 → 属性列 → 必须写进画面的证据 → ❌ 常见降级写法）。

## 为什么按「维度 × 原型」枚举，而不是按翻车案例累加

案例无穷，维度有限。每接一个新题材，按固定 10 维填一行；不是每翻一次车补一条。这样覆盖是可穷举的，不会「永远优化不完」。新增原型时复用同一组维度，不要另起一套。

## 固定维度（所有原型共用，不得删改；不适用就写「不适用」）

1. 身份伦理　2. 头部　3. 面部　4. 眼神　5. 服装轮廓　6. 色彩　7. 武器　8. 姿态　9. 光与氛围　10. 神秘感来源

## 条目

### 武侠 / 中式侠客 · 独行客变体（对照：刺客、忍者）

| 维度 | 侠客（目标） | 刺客 / 隐匿者（易混） | 必须写进画面的证据 | ❌ 常见混写 |
|---|---|---|---|---|
| 身份伦理 | 不事权贵、无军职、来自下层，依「侠」自主行动；**独行客变体＝存在状态**（独来独往、沉默背负、不依附组织），弱化侠义层 | 受雇于权贵、为报酬服务，**需要匿名** | 身份符号可辨（发式、衣领、佩器），不藏 | 把「神秘」直接写成匿名 |
| 头部 | 束发或自然散发，可戴宽檐斗笠覆顶；身份信息（额、鬓、耳）至少部分可读 | 全包头巾 / 巴拉克拉法帽 / 兜帽 | 「中长发松散披垂，发顶遮在斗笠之下，仅鬓侧颈侧几缕发丝露出」 | ①只写「布面罩自鼻梁裹至颈根」→ 把整个头包起来；②高髻＋横插发簪＋鬓发修整干净 → 板正伟光正的制式官样，见 `visual-negative-examples.md` 对照 2 |
| 面部 | 露全脸，或仅面巾遮口鼻，保留眉骨眼窝颧骨的立体结构 | 只露眼或护目镜，五官不可读 | 面巾「自鼻梁下缘系向脑后，颈侧可见系带」 | 蒙面 + 正面死黑，主动放弃五官辨识度 |
| 眼神 | 情绪与人格的主载体：针尖眼神光、视轴平视直视、眉形上扬有眉峰、上眼睑微压成半眯 | 常被遮蔽，读作「扫描目标」 | 虹膜巩膜交界清晰、瞳孔深黑、眉骨投影落在上眼睑、眼周肌肉松弛稳定 | ①写「眼神锐利 / 沉定」等形容词；②「眉形平展」被读成温和无神；③「眉骨压低 + 眉尾下沉 + 眉间竖纹」被读成皱眉瞪眼 |
| 服装轮廓 | 交领右衽、窄袖劲装或长袍，外披斗篷；舒展、有体积与斜线 | 紧身贴体、缩小体积、兜帽高领收口 | 斗篷一角被风掀起，拉出一道自肩线斜向画框边缘的长斜线 | 垂坠贴身 → A 字帐篷，显矮显敦实 |
| 色彩 | 青灰 / 黛蓝 / 皂白粗布，或全黑；低调但不匿形 | 黑 / 深灰 / 靛蓝，为融入暗处 | 低饱和墨黑冷灰，全画面仅一到两处窄冷白高光；主体与背景分属不同明度带 | ①大面积死黑且主体与背景同明度带 → 糊成一片；②把「阴沉」误判成「猥琐」，见 `visual-negative-examples.md` 对照 1 |
| 武器 | 长刀 / 剑明佩，形制可辨，是身份符号 | 短兵器、暗器、可藏匿工具 | 柄 / 护手 / 鞘口三段形制写死，佩戴位置与朝向写明 | 只写「长刀」→ 被画成一根横过身前的黑棍 |
| 姿态 | **静态轴正**：脊柱垂直、肩线水平、胸廓打开、头颈中正、双脚开立重心均匀、纵向拉长 | 含胸圆肩、头前伸、重心蜷、剪影含混 | 「肩线水平、胸廓打开、双脚开立与肩同宽、重心均匀落在两脚之间」 | ①侧身 3/4 + 重心压前脚 + 后脚跟离地 → 缩肩显矮，读作畏缩；②重心均匀但双手垂身侧、目光平视不动 → 站桩。**舒展 ≠ 动势** |
| 光与氛围 | 侧逆轮廓光把人物从暗处剥出来，视线方向留负空间 | 人物被暗处吞没 | 光比约 1:3，沿肩线 / 斗篷边缘 / 鞘口一道连续细亮轮廓线 | 纯影棚平光，或正面完全死黑 |
| 神秘感来源 | 身份可辨、意图不明；**控制信息的位置**：藏身份 / 下半脸 / 来路去向，给足体态的势、眼神内容、剪影辨识度与少数高光钩子 | 物理遮脸 = 信息归零 | 未完成状态（身份待揭、动机不明、去向不明）+ 大面积暗负空间 + 唯一高光钩子 | ①把「神秘」理解成「什么都看不见」；②换成制式正派——已完成状态没有叙事留白 |

**来源**：Wikipedia *Wuxia* / *Ninja* 条目（身份伦理；黑装束源自江户剧场 kuroko 而非史实制服）、公开中文游戏美术行业资料、跨风格视觉调研凝成的 10 维对照表。术语与检验标准见 `visual-dimension-glossary.md`，易混概念的两组特征对照见 `visual-negative-examples.md`。

**需确认**：需求「蒙面」在符号上属匿名词汇，与侠客身份天然相冲。用户坚持蒙面时，路线 A = 只遮下半脸、保留束发额鬓全部身份信息，把神秘感转移到光 / 留白 / 凝视方向；路线 B = 去掉蒙面，只靠氛围与眼神做神秘。两条先让用户选，不要替他定。

## 新增一行的规则

1. 先判定是**新原型**还是已有原型的新维度。新原型复制上面 10 维表头；新维度往固定维度表补，并给不适用的原型标「不适用」。
2. 「必须写进画面的证据」列只写**可见画面语言**（身体部位 + 精确状态 + 参照物），不写形容词；且该部位在最终画面里必须**没被覆盖物吃掉**（见 `visual-negative-examples.md` 对照 7）。
3. ❌ 列只收**实测翻车过的写法**，不收推测。
4. 回填后同步 `preflight.md` 命中清单、`SKILL.md` 索引、`ROADMAP.md` 能力计数、`STRUCTURE.md` 路由表。
5. 与 `word-bank.md` 第三部分·B「气质词→身体语言」分工：那张管**气质形容词 → 姿态**，本库管**角色原型 → 造型部件与区分判据**，互不覆盖。
