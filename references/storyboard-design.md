# storyboard-design — 情节 → 分镜设计方法论

> **这页解决什么**：用户给一段情节/故事（"两人对峙，然后升级，紫方召唤机甲，红方也召唤"），怎么把它**拆成一串可逐个生成的分镜**。这是分镜的**上游设计**，回答"该拍哪些镜头、每个拍什么、什么节奏"。
>
> **它在 skill 里的位置**：是 `shot-continuity.md`（多镜拼接）的**前一步**——shot-continuity 讲"分好镜之后怎么拼不穿帮"，本页讲"从情节怎么拆出分镜"。两者是上下游：**本页拆 → shot-continuity 拼**。
>
> **与既有文件的分工**：
> - `mood-to-shot.md`：单镜氛围 → 整套镜头配置（管"一个镜头怎么拍"）。
> - `shot-continuity.md`：多镜拼接一致性（管"拆完后怎么拼"）。
> - **本页**：情节 → 分镜序列（管"整个故事拆成哪几镜、每镜干嘛"）。三层递进：**拆（本页）→ 单镜拍（mood-to-shot/checklist）→ 拼（shot-continuity）**。
>
> 建立：2026-10-28。来源：实测机甲双塔召唤片 + 吸收外部「分镜脚本与提示词区别」「爆款拆镜公式」「打斗三帧法」的方法论。

## 一、分镜 vs 提示词：一层给用户看，一层给机器看

这是分镜设计的**第一原则**，决定整个产出形态：

| 维度 | 分镜（给用户看） | 提示词（给机器看） |
|---|---|---|
| 给谁看 | 用户（确认用） | 模型（执行用） |
| 语言 | 人话、可读、有剧情 | 机器指令：风格+主体+动作+镜头+光线 |
| 目的 | 让用户判断"内容对不对" | 让模型"生成出画面" |
| 信息取向 | **要不要**（内容取舍） | **长什么样**（画面参数） |

一句话：**分镜是"拍什么"，提示词是"怎么拍"**。

**落地到产出格式**：给用户看的永远是「人话分镜卡片」，不是甩十条提示词让用户看（用户不知道那是"让你改"还是"让你看"）。分镜卡片一行一镜：

```
【镜1 · 对峙 · 8s】
画面：双塔对望，长风衣沉稳 vs 短夹克狂躁，前后景清晰
（最终画面以生成为准）
```

**确认分镜 = 确认提示词的内容**，提示词只是分镜的翻译稿，不再多一道"确认提示词"的关（除非用户明确要求看提示词）。

## 二、从情节拆分镜的节奏骨架

**核心规律：AI 视频好不好看，80% 由镜头结构决定，提示词只负责 20%。** 拿到一段情节，先拆结构，再写每镜提示词。

### 2.1 三段节奏骨架（最值钱的通用结构）

任何一段情节都可归到三拍：

```
钩子（前3秒抓注意力）→ 推进（中段展开）→ 落点（收尾定格/留白）
```

| 拍 | 作用 | 通用做法 |
|---|---|---|
| **钩子** | 前 3 秒抓注意力 | 大主体占屏、或强反差、或一个明确动作起手 |
| **推进** | 中段展开情节 | 因果链一段接一段，不并列（见 shot-continuity 因果闭环） |
| **落点** | 收尾给情绪 | 定格、留白、或反差收尾，让观众有回味 |

### 2.2 单镜时长的安全区（⚠️ 分场景，别一刀切）

外部「爆款拆镜公式」主张"单镜 ≤5 秒、全片 6-8 镜"，**这是信息流广告的规律，不适用于艺术短片**。两者要分开：

| 场景 | 单镜时长 | 全片镜数 | 依据 |
|---|---|---|---|
| **信息流广告 / 爆款短视频** | 1.5–5 秒 | 6–8 镜 | 用户停留判断不到 1 秒，长镜崩坏率升 |
| **AI 短片（艺术向，本 skill 定位）** | 5–15 秒，**长镜头 oner 可到 15s** | 按情节，不硬凑镜数 | 艺术向追求沉浸、流畅的镜头节奏（如《无间道》），长镜头是核心手法 |

**判断标准**：用户要"节奏紧凑抓人"→ 走广告向短镜；用户要"镜头节奏舒服、有氛围"→ 走短片向，可长镜。**别拿广告的"≤5秒"去卡艺术短片的长镜头。**

### 2.3 每镜只装一个主动态

拆镜时，一个镜只放**一个主动态**（一个动作、或一个信息点）。连续动作链（比如"两人过招"）必须拆成多镜——这是下面"三帧法"要解决的。

### 2.4 节奏 = 情绪唤醒曲线（为什么快慢要这么切）

镜头时长不是随便定的，它直接调观众的**情绪唤醒度（arousal）**——这是剪辑节奏的底层原理，跨题材通用、不过期：

- **快切（短镜密排）→ 拉高唤醒**：切得越密、越快，心跳随之上提，适合动作、追逐、爆发、爆款钩子。但**有甜区**——切过头（每镜不到 1 秒连续堆）会超过观众处理带宽，变成"眼花、累、记不住"，不是"爽"。
- **长镜（慢推/固定/oner）→ 压低唤醒、促沉浸**：时间被拉长，观众进入画面、品氛围，适合文艺、情绪、孤独、宿命。《无间道》式流畅的沉浸节奏就靠这个。
- **对比才有节奏**：全快=疲劳，全慢=闷。真正"节奏舒服"是**慢—快—慢的呼吸感**——长镜蓄势 → 关键点快切爆发 → 落点再回到长镜收。单一速度没有节奏。

**落到拆镜**：镜头时长要**服务当前这段的情绪**，不是统一切成一样长。情绪高点（冲击、爆发、钩子）用短；氛围/情绪沉浸段用长；两者交替制造呼吸。写分镜时标清每镜"快/慢"，别一刀切。

## 三、三帧法：拆连续动作（打斗/召唤/爆发等）

连续动作不能写成一串（"抬手→砍下→对方挡"），模型要同时算多人身体+轨迹+接触点，必崩。拆成**三个独立镜头**，靠剪辑连接：

```
起势帧（蓄力·慢）  →  冲击帧（接触·定格或慢放）  →  反应帧（受力·慢）
    0.5–1s                0.1–0.3s                 1–2s
```

| 帧 | 主体 | 动词 | 镜头 | 关键约束 |
|---|---|---|---|---|
| 起势 | 攻击方 | **蓄**（压重心、抬手、握紧） | 中景/近景，稳定 | 慢，全身可见 |
| 冲击 | 武器/接触点 | **接触**（不写"打中"） | 特写，50mm | 必须带"定格"或"慢放" |
| 反应 | 受力方 | **受力**（后仰、退步、脱手） | 中景，稍晃 | 慢，别写"飞出" |

**核心口诀：冲击帧不拍人，拍接触点。** 拍两个人打 → 崩；拍刀锋撞上刀锋的那一寸 → 稳，且更有冲击力。这条同时是过审关键。

**为什么必须拆**：三帧法每镜只有"一个人 + 一个动作 + 一个落点"，模型算得过来；观众看到的节奏反而更快——冲击帧是"定格"，比糊成一片的高速更有力。

**通用化**：三帧法不只用于打斗，任何"连续动作/状态突变"都适用——召唤（蓄力→法阵开→机甲现）、爆发（蓄→炸→震）、崩溃（僵→塌→散）。把"动作链"映射成"蓄→接触→反应"三帧。

## 四、常见情节分镜模板（骨架，往里填内容）

### 4.1 对峙 → 升级 → 召唤（实测案例：机甲双塔）

```
【镜1 · 对峙 · 8s】双塔对望，一静一动（画面给到两人，前后景清晰）
【镜2 · 紫方施法 · 8s】紫方背影抬手托光球（起势）
【镜3 · 紫方法阵 · 8s】水平法阵展开（冲击：能量扩散）
【镜4 · 紫机甲降临 · 15s】机甲从法阵降下（反应/落点，长镜给足仪式感）
【镜5 · 红方施法 · 8s】红方背影高举火球（起势，镜像紫方）
【镜6 · 红方法阵 · 8s】竖直法阵撑开（冲击，方向与紫方相反）
【镜7 · 红机甲穿出 · 15s】机甲破阵穿出（落点，收在野性蓄势）
```

**规律**：① 双方召唤是**镜像对位**（同一套"施法→法阵→登场"，但法阵一横一竖、姿态一静一动）；② 每段召唤自己是一个"蓄→开→现"的三帧法；③ 收尾落点给最长的镜头（机甲登场是高潮，不是过程）。

### 4.2 追逐 / 动作戏

```
【镜1 · 起跑 · 4s】追逐方启动（起势，低机位）
【镜2 · 穿越 · 5s】穿梭场景，背景飞掠（推进，速度感）
【镜3 · 变向 · 4s】急转弯/变向（运动突变）
【镜4 · 逼近 · 5s】逼近或截停（落点）
```

### 4.3 情绪独白 / 氛围空镜

```
【镜1 · 建立 · 8s】环境空镜定氛围（大远景/负空间）
【镜2 · 人物入 · 8s】人物进入，慢推近
【镜3 · 情绪落 · 10s】特写或留白，情绪落在脸上/手上（长镜，不切）
```

## 五、拆分镜时的自检清单

1. **每镜一个主动态**（连续动作已按三帧法拆开）
2. **有因果链**（A 因→A 果，不并列；见 shot-continuity）
3. **节奏有钩子 + 有落点**（开头抓人，结尾留回味）
4. **对位元素显式设计**（对立双方镜像对位，法阵一横一竖这种差异写清楚）
5. **长镜只给高潮/情绪点**，不给过程
6. **单镜时长按场景定**：广告向 ≤5s，艺术短片可 5-15s 长镜
7. **给用户看的是人话卡片**，不是提示词

## 五·补、何时不该拆：分段代价评估

拆镜提高单镜可控性，但会引入三类结构性代价。拆之前先过这张表：

| 代价 | 表现 | 规避 |
|---|---|---|
| 衔接连续性 | 成对首尾帧生成时，模型在尾段收敛到静态尾帧 → 每条末尾近静止，硬切后每处衔接「停一下」 | 提示词避免「纹丝不动 / 僵在原地 / 定在原地」这类静态收尾；生成后裁掉尾段静止帧或加短溶接 |
| 锚图几何一致性 | 前后镜锚图里同一静态物件（柱、门、家具）的大小 / 位置不一致 → 插值时物件「长出来」或跳变 | 锚图同源派生并逐张核对静态几何；别让同一物件在两张锚图里各画各的 |
| 独立失败面 | 每段是一次独立生成与独立计费，N 段＝N 次失败机会＋N 处衔接 | 段数按节拍最小必要，不按「越细越可控」堆 |

**判据**：若题材依赖**连续节奏、情绪累积、人物空间关系**，且目标模型支持单条长生成（含时间戳 / 多镜头调度），应优先整段生成，或先跑一组「整段 vs 分段」对照再定。拆镜不是默认解。模型能力随版本变化，用时核对厂商文档与参数校验，别拿历史时长上限当永久事实。

## 五·补2、反应类镜头的景别与视觉证据

喜剧 / 情绪戏的落点往往在**反应**上，不在动作本身。

- **反应镜要给近景或特写**：惊讶、怀疑、得意、沉思落在脸上，全片中景双人同框会让观众读不到。动作镜与反应镜交替，才有快慢呼吸。
- **关键落点必须有可见证据入画**：「确认某处空无一物」这类桥段，需要把**那处空处本身**拍进画面（低机位插入镜 / 特写）；只写「伸手划过」不够——笑点靠观众看见，不靠提示词声明。
- **锚图语义准确性独立验收**：关键帧不是「有这张图」就行，要逐张核对它是否准确表达了该镜意图。生图提示词丢掉的细节，会被首尾帧硬锁进整段视频。
