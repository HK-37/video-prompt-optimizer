# 易混视觉概念反例对照

> **定位**：评价、对比、评审、改词之前查表。防止把 A 维度的问题误判成 B 维度，进而改错地方。
> **形式**：每条给**两组可枚举的可观察特征组合**，不写评价词、不写结论性褒贬。以下均为中性教学范式，非特定项目案例。
> **配套**：`visual-dimension-glossary.md`（形容词 → 维度 → 画面参数）、`character-typology.md`（原型 → 造型部件）。本文件只收**易混对**，不重复词典内容。

---

## 对照 1 · 阴沉 ≠ 猥琐

| | 特征组合 A：低明度、内敛 | 特征组合 B：体态蜷缩 |
|---|---|---|
| 明度 / 色彩 | 低明度、减饱和、大面积暗部 | 与明度无必然关系 |
| 遮蔽 / 空间 | 高遮蔽、独处、大面积负空间 | 与遮蔽无必然关系 |
| 体态轴 | 脊柱垂直、肩线水平、胸廓打开、头颈中正 | 含胸、圆肩、头前伸、重心蜷缩 |
| 剪影 | 轮廓清晰、有大几何形与斜线 | 剪影含混、肢体空隙消失 |
| 视线 | 平视直视、视轴稳定 | 视线回避、下垂或飘移 |
| 比例 | 纵向拉长、头略小 | 矮塌、头显大、下肢显短 |

**判读规则**：把「暗 / 遮 / 冷」判成 LOW 是维度错配。同一套低明度配置，配 A 组体态读作孤绝与神秘，配 B 组体态读作畏缩。**观感问题先查体态轴与剪影，再查明度。**

## 对照 2 · 挺拔 ≠ 伟光正

| | 特征组合 A：体态轴 | 特征组合 B：身份符号 |
|---|---|---|
| 构成 | 脊柱垂直、肩线水平、胸廓打开、头颈中正、纵向拉长 | 高髻配横插发簪、发际与鬓发修整干净、制式对称、端正仪容、官方标识 |
| 承载的信息 | 身体状态、力量与轴线 | 阶层、职衔、正派归属 |
| 视觉后果 | 避免矮塌内收 | 显得板正、伟光正、像官方设定 |

**判读规则**：「避免畏缩」靠 A 组，不需要 B 组；把两者绑定会把角色推向制式正派。发簪、冠、端正修整属于身份符号，删改它们不改变体态轴。

---

## 对照 3 · 神秘 ≠ 信息归零

| | 特征组合 A：控制信息的位置 | 特征组合 B：信息归零 |
|---|---|---|
| 藏 | 身份、下半张脸、来路与去向 | 连体态、眼神、剪影一起抹掉 |
| 给足 | 体态的势、眼神的开度与视轴、剪影辨识度、一到两处高光钩子 | 无 |
| 画面 | 大面积暗负空间 + 可读的眉眼与轮廓 | 大面积死黑 + 正面无补光，五官与材质均不可读 |
| 读法 | 未完成状态：身份待揭、动机不明、去向不明，留出补全空间 | 已完成的信息封闭：无悬念、无记忆点 |

**判读规则**：神秘来自**留白的位置**，不是可见信息的总量。遮蔽度提高时，必须同步提高眼神与剪影的可读度，否则从神秘滑向沉闷。

## 对照 4 · 低调 ≠ 无装饰

| | 特征组合 A：克制的点缀 | 特征组合 B：通体无装饰 |
|---|---|---|
| 装饰分布 | 集中在腰 / 腕 / 发 / 器 等少数节点 | 全画面无金属件、无纹样、无挂件 |
| 反光 | 点状、低强度、同色系 | 全哑光、无反光梯度 |
| 材质分层 | 布 / 皮 / 金属两到三种质感可辨 | 单一材质、单一明度 |
| 读法 | 私密私服、有身份痕迹 | 制服、夜行衣、剪影道具 |

**判读规则**：减少装饰要减的是**密度与反光**，不是把装饰清零。层级与少数节点本身就是身份信息。

## 对照 5 · 风格化 ≠ 换材质

| | 内容层（要迁移） | 载体层（不迁移） |
|---|---|---|
| 构成 | 剪影几何、块面分层、装备层级、母题重复、廓形 | 哑光树脂 / 石雕质感、统一无毛孔皮肤、做旧、块面化明暗、纯色影棚底、界面与水印 |
| 来源 | 造型设计本身 | 模型雕塑、数字分身、手办、截图等**媒介自带**的副作用 |

**判读规则**：看到「不够风格化 / 太写实」这类比较级形容，先把两张图并排定位差异落在哪一层。**载体特征出现在多张参考里，只能说明这些参考共享同一媒介**，不等于它是需求目标；除非明确要求「就要这个质感」，否则只迁移内容层。

## 对照 6 · 抽卡 ≠ 变体

| | 同词抽卡 | 变体轴 |
|---|---|---|
| 输入 | 同一条提示词重发 N 次 | 锁死造型骨架，每条只放开 1 个非关键维度，产生 N 条不同提示词 |
| 结果 | 大构图一致、差异只在局部细节；约束越密越雷同 | 在受控维度上产生可比较的差异 |
| 适用 | 验证意图编码是否稳定、挑阵发性漂移 | 用户要「几组不同取向」、要多样性 |

**判读规则**：高约束提示词的解空间本就很小，抽卡必然收敛；此时报「四张都很像」不是模型问题，是输入问题。要差异必须改维度，另开样本只会重复付费。

## 对照 7 · 形体判据要落在可见结构

| | 落在可见结构 | 落在被覆盖的部件描述 |
|---|---|---|
| 示例 | 把判据写成**剪影级外轮廓转折**：肩线自颈根水平展开、在肩峰折出近直角、上臂外侧垂直落下；硬质护肩或披肩硬边只是可选承载物 | 只写「肩峰折出直角」而不给外轮廓的水平段与折角位置；或把「向外张开的锐角块面」当成方肩指令 |
| 结果 | 指令有承载物，能被执行 | 指令被覆盖物吃掉，画面无变化 |

**判读规则**：形体判据不必要求某个局部（如肩峰）裸露，但必须落在**剪影级可见的外轮廓几何**上——覆盖物之下仍可读。斗篷、大披肩同样能读出直角肩，靠的是水平肩线＋明确折角，不是靠露出肩峰。反过来，若指令本身把布块写成「向外张开的锐角」，即便露出肩峰也会被画成斜肩。把「软布盖住肩峰」当成唯一根因，是过度归因。

## 对照 8 · 有观点 ≠ 立场对立（评价任务专用）

| | 判断依据充分 | 立场差异化 |
|---|---|---|
| 输入 | 任务事实、可核查数据、画面本身、明确写下的验收标准 | 揣测对方期待、预设需要给出相反结论 |
| 输出 | 事实清单与价值判断分开；结论有依据；敢下判断 | 为显得独立而主动找扣分点，或为迎合而反向改口 |

**判读规则**：评价类任务先列可观察事实清单，再列价值判断，两段物理分开；开工前声明本任务采用哪套评价标准，中途不换；找不到可枚举判据时明确声明「个人观感，非客观结论」；不用同一会话里此前的旧诊断套新对象。**正向迎合与反向唱反调属于同一类错误**——都把「揣测对方心理」放进了判断输入。

## 维护

1. 新增对照时，两组特征必须**可观察、可枚举**，且确实属于不同维度；同维度的强弱差异不收。
2. 只收中性教学范式与可核验的公开行业共识；个人 / 项目经验、具体事件、时间线一律转译成通用表述后再入（遵守 skill 通用化铁律）。
3. 新增对照后同步 `visual-dimension-glossary.md` 第五节的映射行、`preflight.md` 的评价纪律、`STRUCTURE.md` 路由表。
