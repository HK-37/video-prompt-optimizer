# 视觉维度词典（visual dimension glossary）

> **定位**：把「感觉词」翻成**可观察特征**，再翻成提示词。查表判断用，写稿前查。
> **为什么存在**：需求方与执行方通常都不使用同一套美术术语，只能用「帅 / 神秘 / 太写实 / 不对味」沟通。误差不出在信息量，出在**形容词与画面参数之间缺一层可枚举的中间语言**。行业方法论对此有明确表述：宽泛形容词（cool / cute / brave / mysterious）几乎不能区分角色，应替换为可观察的行为与形态特征。
> **铁律**：标签词不进提示词正文。模型不执行「神秘 / 帅 / 有故事感」这类评价词，只执行身体部位、精确状态、参照物。
> **分工**：本文件管「形容词 → 维度 → 画面参数」的映射；`character-typology.md` 管「角色原型 → 造型部件与区分判据」；`word-bank.md` 第三部分·B 管「气质词 → 身体语言」；`visual-negative-examples.md` 管易混概念的两组特征对照。一处知识只有一个家。

## 一、角色设计：形体与剪影

| 维度 | 可观察特征（枚举） | 提示词落法 | 常被误对应的感觉词 |
|---|---|---|---|
| 剪影 silhouette | 填黑后是否仍可辨；外轮廓的转折点；肢体与躯干之间的负空间；大配件形成的几何形（三角 / 矩形 / 斜线） | 写死配件的轮廓与朝向，如「宽檐形成大三角」「剑身形成一道斜向剪影」；写明肢体间的空隙；**形体判据写成剪影级外轮廓转折**（水平段＋明确折角），覆盖物之下仍可读 | 有型、辨识度、气场 |
| 形状语言 shape language | 主导形状族：圆 / 方 / 三角；曲线 / 直线 / 锐角；同一语法在头、肩、衣摆、器物的复现 | 指定大块面的形状倾向与重复位置，不用「圆润」「硬朗」等评价词 | 危险、亲和、稳重、锐利 |
| 比例 proportion | 头身比；头高与躯干长之比；肩宽 / 腰宽；下肢占全身比；夸张方向（头缩小、下肢加长、肩加宽） | 给出比例关系与具体部位，如「头略小、肩宽接近腰宽两倍、腰节上提」 | 修长、敦实、英气、文弱 |
| 姿态轴线 / 重心 | 脊柱垂直或前倾；肩线水平或下溜；胸廓打开或内收；头颈中正或前伸；重心落在双脚之间还是压在前脚 | 逐项写状态，不写「挺拔」；静态轴正与动势是两条不同的路，别混 | 挺拔、猥琐、将动未动 |
| 动线 line of action | 贯穿身体的主导斜线 / 弧线 / 垂直轴；静止时轴线是否仍立得住 | 用具体部件方向描述，如「衣摆掀起一角拉出斜线」 | 动感、张力、势 |
| 细节层级 detail hierarchy | 焦点区（通常为面部与手部）的信息密度 vs 外围的简化程度；是否存在均匀铺满的细碎细节 | 写明「焦点最锐利、其余随景深渐柔」，并把装饰集中在少数节点 | 精致、干净、杂乱 |

**行业共识**：剪影先于细节；细节应聚集在希望被注意到区域并在别处变稀，均匀铺满会变成视觉噪声。检验法：把设计填成纯黑，若角色、意图与主要动作都消失，说明内部细节承担了过多工作。

## 二、元素设计：身份符号与装备层级

| 维度 | 可观察特征 | 提示词落法 |
|---|---|---|
| 身份符号 | 发式、衣领形制、佩器、腰牌、纹样、制式配件——能读出身份、阶层、阵营的部件 | 逐件写形制与佩戴位置；身份符号可辨 vs 刻意抹去，是两类角色 |
| 装备层级 | 大层（外披 / 斗篷 / 围巾）→ 中层（袍 / 甲）→ 附件（腰带 / 护腕 / 挂件）；每一层都改变剪影 | 按层写，先大后小；层与层之间要有明度或材质差异，否则糊成一块 |
| 母题重复 motif | 同一形状 / 材质 / 颜色在 2–3 处复现，形成连贯感 | 指定复现位置，如「暗铜同时出现在带扣、护腕与鞘口」 |
| 装饰密度 | 点缀集中在少数节点（腰 / 腕 / 发 / 器）、低反光、同色系；还是通体无装饰 | 写明节点数量与反光强度。**低调 ≠ 无装饰**：无装饰的纯黑装束容易读成制服或夜行衣 |
| 服装作为证据 | 磨损、修补、风尘、系带磨痕出现在符合使用行为的位置 | 用「袖口磨损」「衣摆沾风尘」等可见痕迹承载经历，不写「饱经风霜」 |

**行业共识**：服装与道具应回答可追溯的问题（谁制作、如何穿脱、适应何种气候、哪里磨损）；细节的价值在于提供叙事线索，而非数量。装饰点到为止往往比堆满更有说服力。

## 三、色彩与明度

| 维度 | 可观察特征 | 提示词落法 |
|---|---|---|
| 明度结构 value structure | 主体与背景是否分属不同明度带；转灰度后主体是否仍可辨 | 写明背景与主体的明度差，如「中深灰底，人物暗部沉入但轮廓光分离」 |
| notan / 2–4 调分组 | 黑白两调的骨架；中间调用于放置平面与层次 | 先决定大块明暗分组，再谈色相 |
| 有限色域 limited palette | 1 主色 + 1 辅色 + 1 点缀；面积大致 60 / 30 / 10；色相数量受控 | 明确列出可用色，如「墨黑、炭灰、中灰与暗铜四色」 |
| 焦点对比 contrast budget | 最高对比、最锐边缘、最亮与最暗是否都留在焦点 | 写明「某某是画面唯一高光」，把对比预算集中在少数点 |
| 饱和度预留 | 多数区域低饱和，少量高饱和留给焦点 | 写「低饱和」+ 指定唯一或两处亮点 |
| 温度偏置 | 先定整体冷暖倾向，再定色相 | 写「冷白主光 / 暖棕底」这类可渲染的光色，不写「氛围温暖」 |

**行业共识**：明度比色相承担更多可读性工作；若灰度图读不出来，调整色相无效。检验法：眯眼测试、缩略图测试、灰度测试。深色主体配暗背景时，必须靠**明度带分离 + 轮廓光**把主体剥出来，否则糊成一片。

## 四、类型学：视觉语法与信息控制

| 概念 | 可观察特征 | 说明 |
|---|---|---|
| 匿名型角色 | 全包头 / 只露眼 / 兜帽压眼 / 高领收口 / 紧身缩小体积 / 短兵器 | 匿名的视觉语言；需要隐藏身份的职业与任务型角色 |
| 自主型角色 | 发式与额鬓可见 / 交领等形制可辨 / 佩器明佩 / 舒展体积 | 身份可读、不需要隐匿的角色 |
| 遮蔽度分级 | 露全脸 → 只遮下半脸 → 只露眼 → 全遮 | 每一级对应不同的身份可读度与信息量，选级前先确认角色是否需要匿名 |
| 信息控制 | **该藏**：身份、下半张脸、来路与去向；**该给足**：体态的势、眼神内容、剪影辨识度、少数高光钩子 | 神秘来自控制信息的位置，不是把信息归零；连体态与眼神一起抹掉，读成「闷」而非「神秘」 |
| 叙事留白 | 未完成状态（身份待揭、动机不明、去向不明）vs 已完成状态（身份、道德、立场明确） | 前者给观者留出补全空间，更容易产生故事感；低明度、高遮蔽、独处、负空间是常用手段 |

**史实提示**：黑装束作为「隐匿者制服」是后世剧场与流行文化的演绎，而非史实常服；史实中的潜行者更多依靠伪装融入环境。做类型区分时，别把流行文化符号当成历史事实。

## 五、形容词 → 维度映射表（核心查表区）

> 用法：拿到评价词，先查「该动的维度」，再查「不该动的维度」，最后按第一至四节取可观察特征落词。**只改被点名的维度**。

| 感觉词 / 评价词 | 该动的维度 | 不该动的维度 | 落词方向 |
|---|---|---|---|
| 神秘、有故事感 | 信息控制、遮蔽度、负空间、光与明度 | 体态轴、五官可读度 | 藏身份与下半脸；给足眼神、剪影与一处高光；视线所向留负空间 |
| 阴沉、孤独、压抑 | 明度、饱和度、负空间、独处构图 | 体态轴、剪影清晰度 | 低明度、减饱和、单人、大面积负空间；保持轴正与直视 |
| 猥琐、LOW、土 | 姿态轴线、剪影、比例、视线 | 明度（暗不是成因） | 脊柱垂直、肩线水平、胸廓打开、头颈中正、直视、纵向拉长 |
| 挺拔、英气 | 姿态轴线、比例 | 身份符号（发簪、制式、端正修整） | 写体态轴的具体状态；挺拔是避免矮塌，不是把角色做成正派官员 |
| 帅、好看、俊 | 回指已定位的具体缺陷，不另立风格轴 | — | 笼统褒义词只作验收信号；先查本表其余行定位到维度，再改 |
| 低调、克制 | 装饰密度、母题重复、反光强度 | 装备层级（不能删到通体无装饰） | 点缀集中在腰 / 腕 / 发 / 器少数节点，同色系低反光 |
| 太写实、不够风格化 | 先做并排定位：差异在**造型内容层**还是**媒介载体层** | 若属载体副作用，则不迁移 | 内容层＝剪影、块面分层、装备层级；载体层＝哑光、无毛孔、做旧、纯色影棚底 |
| 压迫感、危险 | 机位仰角、剪影体量、光比、形状语言 | 表情（避免暴力与狂暴词） | 低机位、宽肩倒三角、三角形状族、硬光比 |
| 有记忆点 | 焦点对比、母题重复、唯一高光钩子 | 细节密度（堆细节反而减弱记忆点） | 把最亮与最暗、最锐边留给一处 |

## 六、来源与分级

写本文件时核验过的公开资料，按可靠性分级；引用术语与方法以 A 级为准，B 级观点仅作补充。

- **A｜多源一致的行业方法论**：角色设计的分层（silhouette / shape language / proportion / color & value / detail hierarchy / motion & pose / story & function）、剪影优先于细节、细节层级、宽泛形容词应替换为可观察特征 —— 见 `https://falcon.so/resources/game-design/character-design`、`https://animatronicsstreet.com/character-design-basics-how-to-create-memorable-characters/`、`https://www.mimiccartoon.com/post/what-makes-a-good-cartoon-character-design`。
- **A｜明度与色彩**：value band discipline、focal contrast、contrast budget、limited palette、saturation reserve、灰度／眯眼／缩略图测试 —— 见 `https://broufart.com/digital-art`、`https://nastyrodent.com/color-theory-for-game-art/`、`https://reigncreativellc.com/blog/color-palettes-for-anime-art`。
- **B｜单一媒体观点（需复核）**：形状语言的情绪对应（圆＝亲和、方＝稳定、三角＝危险）是惯例而非定律；60/30/10 属经验起点而非硬规范。中文服装设计访谈中「遮面、帽饰、束腰、护腕作为视觉符号」「点到为止的表达」可作元素设计旁证。
- **C｜百科史实**：`https://en.wikipedia.org/wiki/Wuxia`、`https://en.wikipedia.org/wiki/Ninja` —— 身份伦理差异、黑装束的剧场来源。

## 维护

1. 新增维度时，必须同时给出「可观察特征」与「提示词落法」；只给术语不给落法的不收。
2. 感觉词映射表按**维度**扩充，不按具体翻车案例累加。
3. 新写内容遵守 skill 通用化铁律：只收方法论、检验标准、可核验的公开行业案例与中性教学范式；个人 / 项目经验、具体事件与时间线一律转译成通用表述后再入。
